# Работа над Util Maker

При первом входе прочитай [общее ТЗ](docs/ТЗ.md), [правила проекта](docs/Работа%20в%20проекте.md) и [правила задач](docs/Работа%20с%20задачами.md). Подробности по компоненту найди в [карте блоков](docs/blocks/README.md).

1. На Ubuntu из корня checkout выполни `make dev-setup`. Требуются GNU Make, доступ к Linux Docker Engine и сеть для первой загрузки зависимостей. Репозиторий должен быть доступен Docker по пути checkout для bind mount.
2. Работай с примонтированными исходниками через `make dev-shell` или `make dev-run CMD="cargo --version"`. Повторяемые команды оформляй отдельными целями Makefile. Файлы создаются с UID/GID пользователя. Cargo и npm используют кэш рабочего каталога.
3. Начни с [задачи первого прототипа](docs/tasks/первый-прототип.md), если пользователь не выбрал другую. Выполняй Linux-проверки в контейнере. Для сборки frontend агенту нужна явная просьба пользователя.
4. Для проверки на Windows передай ревизию, команду локальной сборки и короткие шаги с ожидаемым результатом. Установщик собирает и запускает пользователь на своей машине. В задаче отдельно указывай, что проверено на Linux и что ожидает проверки на Windows.
