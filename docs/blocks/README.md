# Функциональные блоки Util Maker

У каждого компонента есть ТЗ и своя очередь задач. Путь блока одинаков в `docs/blocks/` и `docs/tasks/blocks/`. Например, изменения HTTP-запросов к Google принимает блок `plugins/translator/providers`, а поведение переводчика после получения ответа — `plugins/translator`. Провайдеры поставляются внутри пакета переводчика.

Общие требования к поставке и сквозные сценарии определены в [ТЗ проекта](../specification.md). Как выбрать владельца новой задачи, описано в [правилах работы с задачами](../task-workflow.md).

| Компонент | Ответственность по ТЗ | Очередь |
| --- | --- | --- |
| [Ядро](core/README.md) | Реестр действий, IPC и жизненный цикл процессов, привязки шорткеев, диагностика. | [Задачи](../tasks/blocks/core/README.md) |
| [Desktop-хост](desktop/README.md) | Трей, окна, команды Tauri, отображение настроек и результатов. | [Задачи](../tasks/blocks/desktop/README.md) |
| [Адаптер Windows](platform/windows/README.md) | Регистрация сочетаний, работа с сессией, выделением, экраном и буфером через системный адаптер. | [Задачи](../tasks/blocks/platform/windows/README.md) |
| [SDK и протокол](sdk/README.md) | Схема манифеста, совместимость API и сообщения JSON-RPC между хостом и плагином. | [Задачи](../tasks/blocks/sdk/README.md) |
| [Пакеты](packages/README.md) | Формат .umpkg, подпись и проверка, установка, обновление и откат. | [Задачи](../tasks/blocks/packages/README.md) |
| [Контрольный плагин](plugins/control/README.md) | Эталонный процесс для проверки вызова ping из хоста. | [Задачи](../tasks/blocks/plugins/control/README.md) |
| [Скриншоты](plugins/screenshot/README.md) | Выбор области, аннотации и копирование кадра. | [Задачи](../tasks/blocks/plugins/screenshot/README.md) |
| [Переводчик](plugins/translator/README.md) | Получение выбранного текста, выбор профиля и показ результата. | [Задачи](../tasks/blocks/plugins/translator/README.md) |
| [Провайдеры переводчика](plugins/translator/providers/README.md) | HTTP-запросы к Яндексу и Google, проверка профиля и разбор ошибок. | [Задачи](../tasks/blocks/plugins/translator/providers/README.md) |

## Сквозная приёмка

Номера совпадают с разделом 9 общего ТЗ. Ведущий блок задаёт ожидаемый результат. В проверке участвуют также блоки, перечисленные в правом столбце.

| № | Проверка | Ведущий блок | Участники |
| --- | --- | --- | --- |
| 01 | Чистая установка | [Пакеты](packages/README.md) | Ядро, интерфейс, оба штатных модуля |
| 02 | Внутренний конфликт | [Ядро — шорткеи](core/hotkeys.md) | Desktop-хост |
| 03 | Системный и внешний конфликты | [Ядро — шорткеи](core/hotkeys.md) | Адаптер Windows, desktop-хост |
| 04 | Глобальный вызов | [Ядро — шорткеи](core/hotkeys.md) | Адаптер Windows, desktop-хост |
| 05 | Скриншоты | [Скриншоты](plugins/screenshot/README.md) | Windows-адаптер, ядро |
| 06 | Захват текста | [Переводчик](plugins/translator/README.md) | Windows-адаптер, провайдеры |
| 07 | Два реальных провайдера | [Провайдеры перевода](plugins/translator/providers/README.md) | Переводчик, интерфейс, хранилище секретов Windows |
| 08 | Независимость пакетов | [Пакеты](packages/README.md) | Ядро, SDK, шорткеи |
| 09 | Изоляция сбоя | [Ядро](core/README.md) | SDK, Windows-адаптер, шорткеи |
| 10 | Интерфейс и ресурсы | [Desktop-хост — настройки](desktop/settings.md) | Ядро задаёт [методику замеров](core/diagnostics.md) |
| 11 | Контракт для нового модуля | [SDK](sdk/README.md) | Пакеты, ядро, шорткеи, интерфейс |

Первый прототип соединяет трей, регистрацию одной комбинации, запуск контрольного модуля и показ первого кадра. Уже на этом срезе измеряются простой и холодный отклик. Затем проверяются установка двух версий пакета и конфликты привязок, после них — оба штатных модуля с настройками. Для релизного кандидата проходят все 11 сценариев. Исходники, установщик, пакеты, SDK с примером и инструкцией подписи, инструкции настройки провайдеров, протокол и результаты замеров составляют общую поставку по разделу 9.
