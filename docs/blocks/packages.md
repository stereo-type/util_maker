# Установка, обновление и откат микроприложений

**Результат.** Пользователь устанавливает локальный пакет и обновляет один инструмент при работающем хосте. Реестр сообщает ядру и интерфейсу активную версию, состояние, манифест и доступные действия. Основание — разделы 1, 3, 4 и 9, приёмка 01, 08 и 11 [общего ТЗ](../ТЗ.md).

## Установка и доверие

Windows-установщик для пользователя поставляет хост и два отдельных штатных пакета. Они проходят тот же путь, что и пакет, выбранный из файла. До установки интерфейс показывает имя, издателя, версию, возможности и совместимость.

До запуска менеджер сверяет подпись манифеста, подписанные хеши содержимого, схему, ОС и архитектуру, диапазон API и связь ID с издателем. Ключ штатного издателя поставляется с хостом. Пользователь может добавить открытый ключ другого разработчика по отпечатку в настройках. Обновление модуля подтверждает его издатель. Распаковка разрешена только внутри каталога новой версии. Абсолютные пути, выход через компоненты пути и ссылки на внешние файлы отклоняются.

## Обновление и управление состоянием

1. Подготовить новую версию рядом с действующей. Дать текущему действию завершиться. Другие модули продолжают работать.
2. Через [ядро](host.md) проверить handshake кандидата по [контракту SDK](module-sdk.md). Миграцию настроек выполнять на копии. Если проверка или миграция завершается ошибкой, доступна прежняя пара версии и настроек.
3. Переключить активную версию вместе с её настройками атомарно. При прерывании и повторном запуске выбирается целостная пара. Предыдущая версия с её настройками доступна для отката.
4. Обновить список действий. Для сохранившихся ID оставить назначения, для исчезнувших показать недоступную привязку. При новых предложенных сочетаниях применять [общие правила конфликтов](hotkeys.md).

Отключение освобождает шорткеи и сохраняет настройки для включения. Удаление освобождает сочетания и удаляет учётные данные модуля из хранилища ОС. Установка, замена и откат выполняются без перезапуска хоста.

## Критерии приёмки

- Установить в чистый Windows-профиль без прав администратора. Оба штатных пакета присутствуют в реестре, оба действия видны из трея.
- Во время работы двух модулей обновить один. Текущее действие штатно завершается. После переключения вызывается новый выпуск, второй модуль доступен, прежние ID сохраняют шорткеи. Откат возвращает старую версию и её настройки.
- На повреждённом файле, неверной подписи, смене издателя, несовместимой версии API и выходе из каталога получить отказ до запуска кандидата.
- Прервать обновление на миграции и перед переключением. После восстановления и повторной попытки реестр, файлы и настройки принадлежат согласованной версии. Сценарии несовместимости и прерванного обновления покрыть автоматическими проверками.
