# Контрольный плагин

Контрольный плагин позволяет проверить цепочку «трей или шорткей → ядро → дочерний процесс → ответ хоста» до установки пользовательских инструментов. Он объявляет модуль `org.utilmaker.control` и действие `ping`. Требования к запуску и обмену определяют [ядро](../../core/README.md) и [SDK](../../sdk/README.md).

## Контракт и приёмка

- Хост читает ID, действие и точку входа из [манифеста](../../../../plugins/control/manifest.json). Список запрашиваемых возможностей пуст.
- При `initialize` процесс подтверждает ID и совместимый API. На `ping` возвращает переданный `callId`, источник вызова и PID дочернего процесса. Неизвестное действие возвращает `ACTION_NOT_FOUND`.
- На Linux обмен проверяется через stdio. На Windows пользователь вызывает действие из трея и шорткеем, видит ответ и может вызвать действие повторно после завершения процесса.
