# Микроприложение «QR-коды»

Пакет выполняет две операции офлайн. Пользователь может показать на экране QR-код с текстом или ссылкой, чтобы считать его телефоном. Обратная операция читает QR из области экрана и показывает содержимое перед копированием.

## Пакет и действия

ID пакета — `org.utilmaker.qr-code`, издатель — `org.utilmaker`. Оба действия поставляются в одном подписанном `.umpkg` для Windows 11 x64. Они видны в трее и имеют независимые привязки в редакторе шорткеев хоста. Назначение клавиш, обработка конфликтов и отключение пакета подчиняются общим правилам. [SDK](../../sdk/README.md) · [Шорткеи](../../core/hotkeys.md)

| Действие | Вход | Возможности хоста |
| --- | --- | --- |
| `show-qr` — «Показать QR из текста» | Текущее выделение исходного приложения или явный ввод в окне | `selection.read` через `selection.get` |
| `read-qr-region` — «Прочитать QR с экрана» | Прямоугольная область зафиксированного кадра | `screen.capture` для кадра, `clipboard.write` для копирования результата |

Манифест объявляет объединение возможностей. Каждый handler использует операции своей строки. В первой версии параметры кодирования фиксированы, пользователь настраивает привязки обоих действий.

## Показать QR из текста

1. Прочитать выделение до показа собственного окна, для команды из трея использовать сохранённый внешний контекст. Если есть текст, сразу показать QR и исходный текст. Если выделения нет, источник недоступен или не отдаёт текст, открыть пустое поле с предложением ввести или вставить содержимое. Для известного парольного поля исключить чтение значения и автозаполнение.
2. Ссылка, кириллица, emoji, переносы строк и пробелы должны восстанавливаться после сканирования. Пользователь может отредактировать ввод и обновить код. На пустом вводе или превышении ёмкости одного символа показать причину у поля и убрать прежний код. Усечение содержимого недопустимо.
3. Формировать обычный QR Code Model 2 с уровнем коррекции M. Для Unicode использовать UTF-8 с указанием кодировки ECI. Показывать чёрные квадратные модули на белом фоне с полем минимум четыре модуля со всех сторон. Отрисовывать модули целым числом физических пикселей; при изменении DPI или размера окна пересчитать масштаб. Если код не помещается, дать увеличить окно или сократить текст. [Размер свободного поля QR](https://www.qrcode.com/en/howto/code.html)
4. Esc закрывает окно. В показе QR системный буфер сохраняет прежнее значение. Ручная вставка выполняется пользователем в поле ввода.

## Прочитать QR с экрана

1. До показа рамки получить снимок рабочего стола через SDK, затем дать выбрать область мышью. Использовать физические координаты и геометрию каждого монитора. Декодировать содержимое выбранной области локально. [Доступ к кадру](../../sdk/README.md#доступ-плагина-к-пикселям-кадра)
2. Один текстовый QR открыть в окне предпросмотра. Показать точную строку обычным текстом, в том числе для URL, Wi-Fi, команд и разметки. Декодирование само по себе не открывает браузер, не выполняет команды и не меняет буфер. «Копировать» записывает показанную строку и закрывает окно.
3. Если код не найден или повреждён, предложить выделить область заново. При нескольких обнаруженных кодах попросить выделить один. При неподдерживаемой кодировке либо двоичной нагрузке, которую нельзя представить как текст, показать отдельную причину. Для QR без ECI поддерживать обычный ASCII и корректный UTF-8. Пустой результат не заменяет буфер.
4. Занятость буфера оставляет результат доступным для повтора. Esc отменяет выбор, декодирование или предпросмотр. Повторная команда того же действия активирует его открытое окно. После завершения удалить из памяти снимок и содержимое QR. В диагностике допустимы ID действия, длительность и категория результата. [Диагностика](../../core/diagnostics.md)

## Приёмка

| Среда | Проверка | Ожидаемый результат |
| --- | --- | --- |
| Linux, контейнер | Закодировать URL с параметрами и строку с кириллицей, emoji, пробелами и переносом. Прочитать независимым декодером. Проверить пустую строку и заведомо слишком большой ввод. | Контрольные строки возвращаются целиком. При ошибке ввода прежний символ скрыт, причина видна. |
| Linux, контейнер | Декодировать эталонные изображения QR из стороннего генератора, повёрнутый на 90° код, область без кода, два кода рядом и двоичные данные. | Текст совпадает с эталоном. Для остальных исходов доступны соответствующие сообщения, запись в буфер отсутствует. |
| Windows 11, пользователь | Выделить ссылку в Блокноте, вызвать показ шорткеем и считать QR телефоном. Повторить из трея, с ручным вводом и при масштабе 150%. | Телефон получает точную строку. На пустом и недоступном выделении можно создать QR вручную. |
| Windows 11, пользователь | Выделить QR на втором мониторе, прочитать его офлайн. Закрыть предпросмотр с Esc, затем повторить и нажать «Копировать». Проверить повтор копирования при занятом буфере. | До команды копирования буфер сохраняет прежнее значение. После команды вставляется точный текст, ссылка остаётся закрытой. |

Агент прикладывает фиксированные изображения с ожидаемыми строками и результаты Linux-проверок. Пользователь проверяет реальный обмен с телефоном и Windows-буфер на своей сборке.
