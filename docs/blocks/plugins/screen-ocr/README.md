# Микроприложение «Текст с экрана»

Пользователь обводит текст на изображении, в видео или в окне, где его нельзя выделить мышью. Плагин распознаёт видимые пиксели на этом компьютере, позволяет исправить результат и скопировать его в нужную программу.

## Пакет и действия

| Свойство | Требование первой версии |
| --- | --- |
| Поставка | Отдельный подписанный `.umpkg` для Windows 11 x64. ID `org.utilmaker.screen-ocr`, издатель `org.utilmaker`. Модели и процесс обновляются вместе с пакетом. |
| Действие | `recognize-region` — «Распознать текст в области». Одна точка входа для трея и глобального шорткея. Сочетание назначает пользователь в редакторе хоста. |
| Возможности | `screen.capture` для кадра, `clipboard.write` для копирования текста, `settings.read` для выбора языков. |
| Настройка | В форме плагина поле «Языки распознавания» с вариантами «Русский и английский» (по умолчанию), «Русский», «Английский». Выбор сохраняется для следующих вызовов. |

## Сценарий пользователя

1. По команде получить один снимок виртуального экрана до показа собственных окон. На зафиксированном кадре курсор выделяет прямоугольник в любом направлении. Вырожденное выделение оставляет пользователя в режиме выбора.
2. После отпускания мыши распознавать только выбранный фрагмент. Показать состояние «Распознавание…» и оставить доступной отмену. Сохранить порядок строк видимого блока текста, буквы, цифры и пунктуацию, прочитанные движком.
3. Открыть результат в обычном многострочном текстовом поле. Пользователь может исправить ошибку, выделить или удалить часть текста. «Копировать» или Ctrl+Enter помещает текущую редакцию в буфер и закрывает окно. Пустой результат скопировать нельзя.
4. Если символов нет, показать «Текст не найден» и «Выбрать другую область». При занятом буфере сохранить исправления и предложить повтор. Esc во время выбора, распознавания или редактирования закрывает действие. До успешной команды копирования прежнее содержимое буфера сохраняется.
5. Повторный вызов при открытом окне активирует текущую сессию. После отмены результат завершившегося OCR отбрасывается. При закрытии освободить изображение, текст и ресурсы движка.

## Движок и интеграция

Для v1 выбран Tesseract с локальными моделями `rus` и `eng`. Движок и нужные файлы данных входят в пакет и загружаются по требованию. Это увеличивает размер OCR-пакета, зато на чистой Windows распознавание работает без установки языковых пакетов и скачиваний при первом вызове. У системного `Windows.Media.Ocr` Microsoft указывает требование package identity для desktop-приложений. [Модели Tesseract](https://tesseract-ocr.github.io/tessdoc/Data-Files-in-different-versions.html) · [Условия Windows.Media.Ocr](https://learn.microsoft.com/en-us/uwp/api/windows.media.ocr)

Плагин владеет выбором области, подготовкой изображения, распознаванием и окном результата. За получение пикселей из отдельного процесса отвечает общий контракт SDK. Для обрезки использовать физические координаты кадра с учётом `origin`, `stride` и разных DPI. При недоступном захвате или потере ссылки до чтения предложить новый захват. При ошибке загрузки модели назвать язык и предложить восстановить пакет. Автоматическую передачу переводчику и сетевые запросы v1 не выполняет. Снимок и распознанный текст существуют только в памяти. ## Приёмка

| Среда | Проверка | Ожидаемый результат |
| --- | --- | --- |
| Linux, контейнер | Передать реальному движку эталонный чёткий растр с двумя строками «Ошибка 404» и «File missing», рядом за границей выбора разместить слово «лишнее». | Обе строки распознаны в указанном порядке, слово за границей отсутствует. Пустой кадр даёт «Текст не найден». |
| Linux, тестовые адаптеры | Задержать OCR, отменить вызов и запустить следующий. При копировании вернуть ошибку занятости, затем успех. | Устаревший результат не открыл окно и не изменил буфер. После повтора скопирован исправленный текст ровно один раз. |
| Windows 11, пользователь | На чистом профиле установить пакет, отключить сеть, вызвать из трея и шорткеем. Выбрать текст на мониторе слева от основного и на стыке двух DPI. | Предпросмотр соответствует выбранной области. После правки и копирования в Блокноте виден исправленный многострочный текст. |
| Windows 11, пользователь | Подождать в режиме выбора дольше срока ссылки на кадр, затем отменить. Перезапустить хост, проверить настройку языка и повторить вызов. | Выбор доступен до отмены, прежний буфер сохранён, язык восстановлен. В простое процесс OCR и загруженные модели освобождены. |

Агент передаёт ревизию, версии движка и моделей, эталонный растр, результаты Linux-проверок и команду локальной сборки. Пользователь выполняет проверку в Windows.
