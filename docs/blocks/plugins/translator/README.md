# Микроприложение «Переводчик»

**Результат.** Одно действие «Перевести текст» работает из исходной программы с уже выделенным фрагментом и с выделением после шорткея. Основание — разделы 1, 4 и 6, приёмка 06 и 07 [общего ТЗ](../../../specification.md).

## Получение текста

При вызове модуль получает от [ядра](../../core/README.md) ссылку на исходный контекст. Состояние элемента определяет [Windows-адаптер](../../platform/windows/README.md). При известном парольном поле чтение и сетевой запрос запрещены.

| Состояние источника | Действие переводчика |
| --- | --- |
| Уже выделено слово, строка или фраза | Передать провайдеру ровно выделенный текст. Сохранить исходное выделение. |
| Элемент поддерживает выделение, диапазон пуст | Показать «Выделите текст», оставив фокус в исходной программе. Дождаться одного жеста мыши. Завершение выбора запускает запрос без второго шорткея. Esc или смена исходного приложения прекращают ожидание. |
| Текстовое выделение недоступно | Предложить ручную вставку или ввод с явной командой «Перевести». Защищённый рабочий стол, OCR и чтение чужого процесса с недоступным уровнем привилегий находятся за границей автоматического захвата. |

## Запрос и окно результата

Действие использует активный [плагин-провайдер](providers/README.md), выбранный на странице переводчика. Если ключ плагина не настроен, предложить открыть его настройки. При запросе показать прогресс рядом с выделением, при отсутствии координат — на мониторе источника. Показать перевод как текст и кнопку «Копировать». Только эта команда записывает результат в буфер. Esc закрывает окно и отменяет текущую операцию.

Таймаут сетевого запроса — 10 с. Пользователь может повторить запрос после ошибки. Новый вызов или отмена прекращает обработку прежнего результата. Отправка другому сервису возможна только после выбора его пользователем. Провайдер получает выбранный или введённый текст без окружающего документа, заголовка окна и содержимого буфера.

## Критерии приёмки

- В Блокноте и на обычной текстовой странице Edge проверить оба порядка действий. В тестовом HTTP-адаптере сравнить отправленный текст с выделенным, включая пробелы и переносы строк внутри выделения.
- При пустом диапазоне подсказка оставляет фокус в источнике. По Esc, смене приложения во время ожидания и попытке вызова в известном парольном поле зафиксировать ноль запросов. При неподдерживаемом выделении ручная вставка отправляется только по команде.
- Вызвать перевод с отсутствующим ключом, открыть нужный профиль, затем провести успешный запрос. Проверить позицию окна, копирование и сохранение исходного текста.
- Задержать ответ, отменить действие и запустить новое. Поздний ответ первого вызова не меняет новое окно или буфер.
