# Интерфейс и настройки

**Результат.** Пользователь видит доступные инструменты, понимает причину недоступности действия и может исправить настройку на той же странице. Окно настроек открывается по запросу и освобождается при закрытии. Основание — разделы 2, 3, 4, 6 и 7, приёмка 01–03, 07 и 10 [общего ТЗ](../ТЗ.md).

| Экран | Данные и доступные действия |
| --- | --- |
| Микроприложения | Основной экран показывает иконку, имя, версию, состояние и переключатель каждого пакета. Пользователь может выбрать локальный файл для установки. Статус переводчика «Нужна настройка» ведёт к выбору провайдера. |
| Страница микроприложения | Список действий, их привязки и собственные настройки модуля. Форма строится из схемы пакета. Для переводчика здесь же доступны профили и проверка подключения. Команды обновления из файла, отката и удаления обращаются к [менеджеру пакетов](packages.md). |
| Шорткеи | Общий список сочетаний, владельцев и причин недоступности с поиском по модулю, действию и клавишам. Редактор поддерживает запись с клавиатуры, выбор клавиш по отдельности, удаление и восстановление рекомендованной привязки. |
| Общие настройки | Автозапуск при входе, тема, доступ к локальному журналу. Предусмотреть добавление доверенного открытого ключа разработчика с проверкой отпечатка в настройках. |

При вводе и сохранении сочетания экран отображает решение [реестра шорткеев](hotkeys.md). Для внутреннего конфликта показываются оба владельца и выбор «Отмена» / «Переназначить». Для системного запрета доступен выбор другого сочетания. Ошибка отображается у соответствующего поля с доступным следующим действием. Настройки принадлежат текущему пользователю и переживают аварийное завершение. Секретные поля после сохранения обращаются к хранилищу ОС.

## Оформление и приёмка

- Интерфейс на русском языке. Стартовая тема следует за Windows. Иконки трея, модулей и команд узнаваемы в светлой и тёмной теме.
- При 100%, 150% и 200% масштаба читаются подписи и доступны основные команды. Статусы выражены также текстом. У кнопок только с иконкой есть подсказка и доступное имя.
- С клавиатуры найти действие, проверить видимый Tab-фокус, ввести сочетание, отменить и подтвердить переназначение. При системном конфликте сохранение недоступно также с клавиатуры.
- Со стартового экрана перейти по статусу переводчика к профилю, проверить подключение и сменить провайдера. При следующем вызове используется выбранный профиль. Закрыть и снова открыть окно, проверить сохранённые значения.
