# Платформенный адаптер Windows

**Результат.** Ядро и SDK получают системные возможности через один интерфейс. Первая реализация рассчитана на Windows 11 x64 и права обычного пользователя. Основание — разделы 1–6 и 8, приёмка 03–06 и 09 [общего ТЗ](../ТЗ.md).

| Операция | Контракт с потребителем |
| --- | --- |
| Трей и сессия | Создать и восстановить иконку и меню, вернуть событие команды. Сообщить ядру о возобновлении сессии. Применить настройку автозапуска для текущего пользователя. |
| Глобальная клавиатура | Выполнить регистрацию и освобождение через `RegisterHotKey` и соответствующую системную операцию. Доставить одно событие при удержании. Вернуть известную системную функцию из версионированного перечня, факт резерва или причину отказа регистрации. Правило переноса между действиями определяет [реестр шорткеев](hotkeys.md). |
| Контекст и выделение | Выдать ссылку на исходное внешнее окно и элемент на время вызова. Через UI Automation различать выделенный текст, пустой диапазон у курсора, неподдерживаемое выделение, парольное поле и потерю источника. Дать возможность однократно дождаться завершения выбора. Снять подписки после получения текста или отмены. |
| Мониторы и кадр | Вернуть геометрию с явно указанными единицами, масштабом и положением относительно виртуального рабочего стола. Поддержать отрицательные координаты и разный DPI. Передать снимок через буфер со сроком жизни, определённым в [протоколе](module-sdk.md). |
| Буфер обмена | По явной команде записать текст или изображение в формате, доступном стандартной вставке Windows. При занятости вернуть ошибку, позволяющую повторить копирование. |
| Секреты | Сохранить, получить, заменить или удалить секрет текущего пользователя для конкретного модуля и профиля. В обычной конфигурации остаётся ссылка на запись. |

Публичный интерфейс выражает доступность возможности, необходимость системного разрешения и потерю контекста. Win32-дескрипторы, виртуальные коды клавиш и пути ОС остаются внутри адаптера. Тот же контракт служит основой для последующих реализаций Ubuntu и macOS.

## Критерии приёмки

- В реальной Windows-сессии доставить событие при фокусе в Блокноте и браузере, проверить занятую извне комбинацию, восстановление после сна и перезапуска Explorer.
- В Блокноте и Edge отдать ровно выделенный текст. Пустое выделение допускает ожидание выбора. Известное парольное поле возвращает запрет до чтения текста. Esc и смена исходного приложения прекращают ожидание.
- Захватить контрольную область на мониторе слева от основного и на границе разных DPI. Сверить физические размеры и содержимое при вставке в Paint.
- Записать два тестовых секрета переводчика. Замена одного профиля сохраняет второй, удаление модуля очищает обе записи.
