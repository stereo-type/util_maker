# Сводный список задач Util Maker

Для первого запуска на Windows начните с общей задачи. SDK, вызов из ядра и регистрацию в Windows ведите в связанных карточках. Каждый из десяти результатов ниже можно начать отдельно по ТЗ блока. Условия интеграционной и ручной проверки указаны в карточках.

## Ведение статусов

- **К выполнению** — задачу можно брать в работу.
- **В работе** — исполнитель начал реализацию.
- **На ревью** — изменения готовы к проверке. В карточке указаны выполненные проверки и оставшиеся шаги, включая ручную приёмку на Windows, если она нужна. При доработке вернуть «В работе».
- **Заблокирована** — в карточке указаны препятствие и условие продолжения.
- **Выполнена** — критерии приёмки подтверждены, результат записан в карточке.

При создании задачи добавьте строку в таблицу. При смене статуса обновите карточку и её строку в одном изменении. Завершённые строки сохраняйте со ссылками. [Правила ведения задач](../Работа%20с%20задачами.md).
