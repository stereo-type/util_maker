# Измерять холодный отклик каждого плагина до первого кадра

**Статус** — 🛠️ В работе

[Этап 4 плана развития](../../../roadmap.md#4-принять-первую-поставку-windows) · [ТЗ блока](../../../blocks/core/diagnostics.md)

Связать событие шорткея с первым видимым кадром соответствующего плагина. Обновить существующую методику и `scripts/measure-windows.ps1`, который сейчас агрегирует значения `since_event_ms`.

**Зависимости для старта** — [Выбирать область и редактировать снимок поверх рабочего стола](../plugins/screenshot/region-editor.md), [Связать выделение и окно результата с действием перевода](../plugins/translator/translate-selection.md).

## Критерии приёмки

- [ ] Записи позволяют отличить холодные вызовы по модулю и действию и построить отдельный p95 для каждого. Окончание облачного запроса не подменяет момент первого кадра.
- [ ] При неполной выборке виден размер выборки. Для памяти и CPU учитываются хост и его дочерние процессы. Журнал не содержит текста, снимков, ключей или чувствительных URL.

## Проверка

На Linux проверить разбор искусственного журнала с двумя действиями и секретным контрольным значением. В Windows пользователь собирает реальные метрики по методике блока.
