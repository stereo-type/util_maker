# Измерять холодный отклик каждого плагина до первого кадра

**Статус** — 👁️ На ревью

[Этап 4 плана развития](../../../roadmap.md#4-принять-первую-поставку-windows) · [ТЗ блока](../../../blocks/core/diagnostics.md)

Связать событие шорткея с первым видимым кадром соответствующего плагина. Обновить существующую методику и `scripts/measure-windows.ps1`, который сейчас агрегирует значения `since_event_ms`.

**Зависимости для старта** — [Выбирать область и редактировать снимок поверх рабочего стола](../plugins/screenshot/region-editor.md), [Связать выделение и окно результата с действием перевода](../plugins/translator/translate-selection.md).

## Критерии приёмки

- [x] Записи позволяют отличить холодные вызовы по модулю и действию и построить отдельный p95 для каждого. Окончание облачного запроса не подменяет момент первого кадра.
- [x] При неполной выборке виден размер выборки. Для памяти и CPU учитываются хост и его дочерние процессы. Журнал не содержит текста, снимков, ключей или чувствительных URL.

## Что сделано

- `LogEntry` получил `firstFrameMs` и `cold`; `with_first_frame` фиксирует первый видимый кадр отдельно от `durationMs` всего вызова.
- `metrics::summarize`/`read_jsonl` строят `Percentiles` отдельно по `moduleId + actionId` и отдельно для холодных и тёплых вызовов; `totalRecords`, `frameSamples` и `malformedRecords` показывают неполноту выборки.
- `scripts/measure-windows.ps1 -InvokeBenchmark` читает `util-maker.jsonl`, печатает размер выборки и p95 по каждой группе, а старый текстовый `since_event_ms` оставлен как резервный путь.
- В методику добавлено явное правило: завершение облачного запроса не заменяет `firstFrameMs`; память и CPU по-прежнему считаются по дереву процессов хоста.

## Проверка

Linux, контейнер `util-maker-dev:local`:

- `cargo test -p util-maker-core --test action_metrics` — 2/2:
  - искусственный JSONL с двумя действиями и холодными/тёплыми вызовами даёт отдельные p95 и размеры выборки;
  - запись с секретом в `message` не попадает в сериализованную сводку;
  - при отсутствии `firstFrameMs` две завершённые записи видны как `frameSamples=0`, а не как нулевой отклик.
- `make check` — 106 тестов, Clippy и rustfmt без замечаний.
- Синтаксис PowerShell-скрипта проверяется на Windows при реальном замере; Linux-тест покрывает разбор журнала, не запуская Windows API.

Ревизия для Windows — `645d24d`: выполнить `scripts/measure-windows.ps1 -InvokeBenchmark` на журнале с 50 вызовами и сверить p95 по каждому `moduleId + actionId` отдельно для `cold=true/false`.
