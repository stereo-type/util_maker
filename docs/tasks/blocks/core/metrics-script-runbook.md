## Наблюдение

`scripts/measure-windows.ps1 -InvokeBenchmark` падает с ошибкой разбора PowerShell
около строки 151. Кроме того, инструкция предлагает вручную сделать 50 холодных
вызовов, что неудобно и легко воспроизводится с ошибкой.

Пункт «p95 отдельно по `moduleId + actionId` и `cold=true/false`, размер выборки,
отсутствие пользовательских данных» не имеет понятной процедуры проверки.

## Критерии приёмки

- [ ] Скрипт запускается без синтаксических ошибок в Windows PowerShell и PowerShell 7.
- [ ] Есть одна команда или скрипт, который сам выполняет 50 холодных вызовов действия и пишет журнал; ручной счёт вызовов не требуется.
- [ ] Вывод содержит p95 отдельно по каждому `moduleId + actionId` и отдельно для `cold=true` и `cold=false`, а также размер каждой выборки.
- [ ] Если выборка неполная, это видно в выводе; отсутствие `firstFrameMs` не превращается в нулевой отклик.
- [ ] В инструкции указаны подготовка журнала, путь к нему, команда запуска и что именно записать в карточку.
- [ ] В журнале нет текста, снимков, ключей и URL с секретами.
