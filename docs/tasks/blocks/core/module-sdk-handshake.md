# Согласовать версию API при запуске модуля

**Статус** — ✅ Выполнена

**Основание** — [ТЗ блока «SDK»](../../../blocks/sdk/README.md).

Реализовать initialize для SDK и контрольного модуля. За основу взять IPC из раздела 4 общего ТЗ. Проверить обмен на Ubuntu через stdin/stdout.

## Критерии приёмки

- [x] Совместимая версия проходит handshake за отведённые 3 с.
- [x] Несовместимая версия, повреждённый JSON и ответ после таймаута дают различимые ошибки.
- [x] Диагностика контрольного процесса не попадает в stdout с JSON-RPC.

## Что сделано

- `ModuleProcess::spawn_with_args` — запуск модуля с аргументами и отдельным приёмником диагностики, чтобы тесты могли включать управляемые сбои.
- В ядре ошибка модуля `HOST_API_INCOMPATIBLE` (код 1004) переводится в `CoreError::IncompatibleApi`, поэтому несовместимость версии отличима от таймаута и нарушения протокола.
- `crates/fixture-module` — тестовый модуль с режимами `ok`, `incompatible`, `module-incompatible`, `garbage`, `late`, `silent`, `stderr`. В поставку не входит.
- `crates/core/tests/handshake.rs` — проверка всех исходов рукопожатия на реальных процессах; общий поиск бинарников вынесен в `crates/core/tests/support/mod.rs`.

## Проверка

Linux, контейнер `util-maker-dev:local`:

- `make test` — 18 тестов пройдено, в том числе 7 тестов рукопожатия:
  - совместимый модуль подтверждает API 1.0.0 не дольше 3 с;
  - модуль с API 2.0.0 отклоняется с `host_api_incompatible`;
  - отказ модуля от hostApi 1.0.0 (код 1004) также даёт `host_api_incompatible`;
  - повреждённый JSON даёт `protocol_violation`;
  - поздний ответ: первый handshake завершается `module_timeout` через 3 с, поздний ответ пропускается, повторный handshake успешен;
  - диагностика реального `control-module` попадает в stderr-приёмник, а stdout остаётся JSON-RPC;
  - коды трёх отказов попарно различаются.
- `make lint` — Clippy без предупреждений при `-D warnings`.
- `make fmt` — форматирование без изменений.

Пользователь подтвердил работу прототипа после изменений; автоматические проверки handshake пройдены.
