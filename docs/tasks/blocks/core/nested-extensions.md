# Подключать и вызывать плагины-расширения микроприложений

**Статус** — ✅ Выполнена

[ТЗ ядра](../../../blocks/core/README.md) · [Контракт плагинов-расширений](../../../blocks/core/extensions.md) · [ТЗ SDK](../../../blocks/sdk/README.md)

Расширить реестр ядра: связать установленные пакеты-расширения с точками
родителя, хранить выбор активного плагина и маршрутизировать вызовы родителя
в дочерний процесс. Родитель не должен знать путь к чужому исполняемому файлу
и не должен иметь возможности обойти выбор пользователя.

**Зависимости для старта** — [Описать контракт плагинов-расширений в манифесте и SDK](../sdk/extension-manifest.md).

**Для сквозной проверки** — [Показывать плагины-расширения на странице микроприложения](../desktop/extension-packages-ui.md), [Перевести переводчик на провайдеров-плагинов](../plugins/translator/provider-extension-point.md).

## Критерии приёмки

- [x] `HOST_API_VERSION` поднят до `1.1.0`; пакеты расширений с прежним диапазоном `hostApi` отклоняются, а обычные пакеты на `1.0.x` продолжают работать.
- [x] Реестр строит индекс вкладов из активных манифестов и не запускает процессы при чтении. Вклад активен только при наличии включённого родителя, совпадающего контракта и совместимой версии.
- [x] Публичный API ядра позволяет прочитать и изменить выбор для точки `single` с проверкой родителя и вклада. Выбор сохраняется по `moduleId + pointId` и переживает перезапуск. Без явного выбора единственный доступный вклад выбирается автоматически; при нескольких доступных вкладах возвращается `EXTENSION_NOT_SELECTED`.
- [x] Отключение, удаление или несовместимость выбранного плагина не стирает сохранённый ID; при восстановлении плагина прежний выбор снова действует. Отключение родителя скрывает точку и вклады, но сохраняет дочерние пакеты.
- [x] `extensions.list` возвращает только точки вызвавшего родителя и доступные вклады без запуска процессов. `extension.invoke` принимает только точку родителя и только активный совместимый вклад.
- [x] Дочерний процесс запускается со своими возможностями, настройками и секретами. Возможности родителя не наследуются, чужие секреты недоступны, локальный идентификатор вызова и связь с родительским вызовом попадают в журнал.
- [x] Отмена родителя отменяет дочерний вызов; таймаут, падение и нарушение протокола плагина дают `EXTENSION_FAILED` с ID плагина и не ломают родителя, другие вызовы и трей.
- [x] Поздний ответ завершённого дочернего вызова игнорируется, его процесс и закреплённые ресурсы освобождаются. Активный вызов не даёт переключить версию плагина.
- [x] Пакет-расширение без действий не появляется в меню трея и общем списке действий.

## Что сделано

- `HOST_API_VERSION` — `1.1.0`; обычные пакеты с диапазоном `1.0.x` продолжают проходить проверку.
- `Registry` строит индекс вкладов из манифестов, хранит выбор по паре `moduleId + pointId` в `extensions.json`, автоматически выбирает единственный доступный вклад и возвращает `EXTENSION_NOT_SELECTED` при нескольких.
- `extensions.list` отдаёт только точки вызвавшего родителя; `extension.invoke` запускает только активный совместимый вклад в дочернем процессе с его возможностями и настройками.
- Отмена родителя останавливает дочерний вызов; таймаут и падение дают `EXTENSION_FAILED` с ID плагина, поздний ответ не влияет на новый вызов.
- Добавлен `crates/fixture-extension` и тесты `crates/core/tests/extensions.rs`: выбор и сохранение, совместимость, изоляция возможностей, ошибки, таймаут и отмена.

## Проверка

Linux: `make check`, тесты `util-maker-core` с тестовым родителем и
`fixture-extension`:

- выбор одного и нескольких вкладов, сохранение и восстановление выбора;
- отказ вкладу без родителя, с чужим контрактом и несовместимой версией;
- вызов только активного плагина и отказ обхода выбора;
- изоляция настроек и секретов родителя и ребёнка;
- отмена, таймаут, падение и поздний ответ дочернего процесса;
- обновление и удаление плагина во время активного вызова.

Windows: отдельных действий для этой карточки нет; сквозной сценарий с
переводчиком проверяется в карточке провайдеров.

Пользователь подтвердил результат: плагины-расширения подключаются и вызываются, замечаний нет.
