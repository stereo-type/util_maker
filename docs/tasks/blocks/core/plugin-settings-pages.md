# Показать установленные микроприложения и их настройки

**Статус** — ✅ Выполнена

**Основание** — замечание пользователя к демонстрационному экрану «Шорткеи»: общие настройки должны показывать установленные плагины, их действия и собственные параметры, а сочетание должно принадлежать действию внутри микроприложения, а не ядру.

Сейчас модель данных уже использует пару `moduleId + actionId`, но интерфейс показывает только демонстрационный список действий. Нужен настоящий экран микроприложений поверх реестра пакетов.

## Критерии приёмки

- [x] Основной экран показывает установленные пакеты: иконку, имя, версию, состояние и переключатель.
- [x] У каждого микроприложения есть страница со списком действий, их сочетаниями и собственными настройками из манифеста.
- [x] Сочетание назначается действию `moduleId + actionId`; страница модуля не требует правки ядра.
- [x] Демонстрационные записи «Скриншоты» и «Переводчик» заменены реальными пакетами или явно помечены как отсутствующие.
- [x] Переход между списком и страницей модуля работает с клавиатуры, настройки сохраняются.

## Что сделано

- Экран «Микроприложения» строится командой `plugins`: установленный контрольный модуль читается из манифеста, «Скриншоты» и «Переводчик» явно помечены как неустановленные пакеты.
- Страница микроприложения показывает действие, его описание и сочетание; для контрольного модуля доступны «Вызвать» и «Изменить сочетание».
- Редактор сочетания меняет реальную регистрацию Win32 через `change_control_shortcut`; системный резерв и занятость возвращаются с причиной, прежнее сочетание восстанавливается при отказе.
- Демонстрационный блок «Шорткеи» удалён из основного экрана; привязка хранится по `moduleId + actionId`.
- Модальное окно редактора по центру с затемнением, без скачка ширины: у `html` зарезервировано место под полосу прокрутки.

## Проверка

Linux, контейнер `util-maker-dev:local`:

- `make test` — 63 теста.
- `make lint` — Clippy без предупреждений, `make fmt` — без изменений.
- `make build-windows` — установщик собран, интерфейс встроен в хост.

Windows (ожидает проверки пользователем):

1. «Микроприложения»: контрольный модуль установлен, «Скриншоты» и «Переводчик» — «не установлен».
2. Открыть контрольный модуль: видны действие «Проверить связь» и сочетание `Ctrl+Shift+U`; «Вызвать» даёт результат.
3. «Изменить сочетание»: модалка по центру, затемнение без прыжка ширины; сохранить `Ctrl+Shift+3`, затем вернуть `Ctrl+Shift+U`.
4. Ввести `Win+L` или занятое сочетание — ошибка с причиной, прежнее сочетание продолжает работать.
5. Автозапуск и журнал на месте; закрытие настроек и «Выход» работают.

Пользователь подтвердил работу в Windows 11 и закрыл задачу в версии 0.4.1.
