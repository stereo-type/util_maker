## Критерии приёмки

- [ ] По типу и версии перечислены только совместимые доступные реализации. Отдельно возвращаются причины недоступности сохранённых назначений. Чтение каталога не запускает процесс и не обращается к сети.
- [ ] Два подключения одной реализации имеют разные неизменяемые ID. Два потребителя выбирают подключения и папки независимо. Переименование сохраняет привязку, новый аккаунт с тем же именем её не наследует.
- [ ] После отключения, отката и удаления обновляются зависимые слоты. Удаление потребителя не удаляет общий аккаунт. При одновременных изменениях и прерванной записи профиль и его связи восстанавливаются согласованно.

## Проверка

Linux, временный профиль, два экземпляра потребителя, два аккаунта, рестарт между изменениями и тест прерванного сохранения.
