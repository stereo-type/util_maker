## Критерии приёмки

- [ ] Хост проверяет живой контекст, объявленный слот, `providers.call`, обе версии контрактов, доступность подключения и операции. Подмены вызывающего приложения, реализации, папки и подключения отклоняются.
- [ ] Сервис передаёт операцию через `extension.invoke` точки `binding`. Одновременные запросы идут в разные аккаунты даже при одном процессе-потребителе в тестовой схеме с двумя слотами. Переводчик с `single` работает как раньше.
- [ ] Правила времени для ввода в настройках и сохранения определены отдельно. Отмена, падение, таймаут и поздний ответ не затрагивают другие процессы. После выхода возвращаются ресурсы, в журнале остаются только технические метаданные.

## Проверка

Linux, настоящие тестовые дочерние процессы с задержкой, отменой и аварийным выходом. Подтвердить маршруты для двух независимых вызовов и отказ незаявленной операции.
