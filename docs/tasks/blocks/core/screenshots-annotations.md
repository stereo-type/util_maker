# Нанести стрелку и рамку на выделенную область

**Статус** — ✅ Выполнена

**Основание** — [ТЗ блока «Скриншоты»](../../../blocks/plugins/screenshot/README.md).

Реализовать формирование итогового изображения по кадру, прямоугольнику в физических пикселях и списку аннотаций. Для проверки использовать контрольный кадр в памяти.

## Критерии приёмки

- [x] Размер результата совпадает с размером выбранного прямоугольника, включая область с отрицательными координатами рабочего стола.
- [x] После добавления стрелки и рамки отмена последней правки оставляет только стрелку.
- [x] При копировании без аннотаций результат совпадает с исходной областью пиксель в пиксель. Панель и маркеры в результат не входят.

## Что сделано

- `plugins/screenshot` — `Frame` с началом координат виртуального рабочего стола, `Selection` в физических пикселях и `Annotation::{Arrow, Rectangle}`.
- `render` вырезает прямоугольник с учётом отрицательных координат, рисует стрелку с наконечником и рамку заданной толщины; всё за пределами выбранной области отбрасывается.
- Отмена последней правки — удаление последнего элемента списка аннотаций; панель и маркеры в кадр не входят.

## Проверка

Linux, контейнер `util-maker-dev:local`:

- `make test` — 63 теста, в том числе 4 теста скриншотов:
  - выборка с отрицательным origin даёт размер ровно 20×10 и пиксель из исходной точки;
  - без аннотаций результат совпадает с областью кадра пиксель в пиксель;
  - после удаления прямоугольника его граница снова исходная, стрелка остаётся;
  - пустая или выходящая за кадр область отклоняется.
- `make lint` — Clippy без предупреждений, `make fmt` — без изменений.

Пользователь подтвердил работу в Windows 11 и закрыл задачу в версии 0.4.1.
