# Пройти основные настройки с клавиатуры при разных масштабах

**Статус** — ✅ Выполнена

[Этап 4 плана развития](../../../roadmap.md#4-принять-первую-поставку-windows) · [ТЗ блока](../../../blocks/desktop/settings.md)

Довести до приёмки поиск действия, переназначение сочетания и смену профиля на страницах реальных модулей.

**Зависимости для старта** — [Подключить редактор и глобальные клавиши к общему реестру](live-shortcuts.md), [Управлять локальными пакетами из настроек](package-management.md), [Показывать и сохранять настройки плагина по схеме манифеста](settings-form.md).

## Критерии приёмки

- [x] В каждом сценарии виден фокус, Tab достигает всех команд, Enter подтверждает, отмена возвращает в ожидаемую точку. Системный запрет нельзя обойти с клавиатуры.
- [x] При масштабе 100%, 150% и 200% основные команды доступны в светлой и тёмной темах. У иконок есть доступное имя и подсказка, состояние и ошибка выражены текстом.

## Проверка

Проверить разметку и обработчики локально. Передать пользователю матрицу клавиатуры, тем и масштаба для Windows. Сборка frontend выполняется только по явному запросу.

## Что сделано

- Фокус возвращается на кнопку, открывшую диалог сочетания.
- Tab зациклен внутри модального окна; Esc закрывает его.
- У иконок и переключателей есть доступные имена.
- Поле сочетания связано с текстом ошибки через `aria-describedby`.
- Список микроприложений размечен как список.

## Осталось проверить на Windows

Матрица: масштаб 100/150/200 % × светлая/тёмная тема. В каждой ячейке:

- [x] Открыть настройки, пройти Tab по списку, поиску, кнопкам действий,
  полям формы, упаковке и нижним кнопкам. Фокус виден на каждом шаге.
- [x] Enter на «Открыть» открывает модальное окно; Esc закрывает его и
  возвращает фокус на «Открыть».
- [x] В модальном окне Tab не выходит за пределы; «Сохранить»/«Отмена»
  срабатывают с клавиатуры.
- [x] Найти действие поиском, открыть редактор сочетания, назначить валидное
  сочетание, сохранить; проверить, что новое сочетание отображается.
- [x] Ввести занятое сочетание: ошибка видна текстом, обойти запрет с
  клавиатуры нельзя.
- [x] Сменить профиль переводчика (Яндекс/Google), сохранить, открыть поле
  ключа; всё доступно без мыши.
- [x] Иконки имеют доступное имя/подсказку, состояния и ошибки — текст, а не
  только цвет.
- [x] На 200 % нет обрезанных кнопок, горизонтальной прокрутки и наложений;
  модальное окно прокручивается внутри.

Если все пункты проходят, пришлите версию, масштаб/тему и результаты по
ячейкам — задача закрывается.

Проверено пользователем на Windows 0.4.11: матрица 100/150/200 %, светлая и тёмная темы, Tab/Enter/Esc и модальные окна.
