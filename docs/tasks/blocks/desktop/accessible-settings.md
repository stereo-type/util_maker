Довести до приёмки поиск действия, переназначение сочетания и смену профиля на страницах реальных модулей.

**Зависимости для старта** — [Подключить редактор и глобальные клавиши к общему реестру](live-shortcuts.md), [Управлять локальными пакетами из настроек](package-management.md), [Показывать и сохранять настройки плагина по схеме манифеста](settings-form.md).

## Критерии приёмки

- [ ] В каждом сценарии виден фокус, Tab достигает всех команд, Enter подтверждает, отмена возвращает в ожидаемую точку. Системный запрет нельзя обойти с клавиатуры.
- [ ] При масштабе 100%, 150% и 200% основные команды доступны в светлой и тёмной темах. У иконок есть доступное имя и подсказка, состояние и ошибка выражены текстом.

## Проверка

Проверить разметку и обработчики локально. Передать пользователю матрицу клавиатуры, тем и масштаба для Windows. Сборка frontend выполняется только по явному запросу.
