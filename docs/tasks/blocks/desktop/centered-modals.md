# Показывать все всплывающие окна по центру экрана

**Статус** — 📥 К выполнению

**Основание** — [Стиль интерфейса](../../../ui-style-guide.md) · [Окно результата](result-window.md)

## Наблюдение

Окно ошибки плагина появилось заметно ниже и не по центру — оно
позиционируется относительно курсора или случайной точки. Так же ведут себя
другие служебные окна.

## Ожидаемое поведение

- Все модальные и служебные окна открываются по центру **активного монитора**.
- Если окно уже открыто, оно перемещается в центр, а не остаётся на старом месте.
- Позиция не зависит от курсора, места вызова и предыдущего окна.
- На нескольких мониторах окно центрируется на том, где находится фокус.
- Размер окна учитывает рабочие области и масштаб 100/150/200 %.

## Критерии приёмки

- [ ] Окно ошибки плагина открывается по центру.
- [ ] Окно результата, подтверждения и настройки — по центру.
- [ ] Позиция не зависит от положения курсора.
- [ ] Повторный вызов не оставляет окно смещённым.
- [ ] Проверено на двух мониторах и разных DPI.

## Проверка

Windows: вызвать ошибку плагина, подтверждение удаления и настройки с разных
мониторов; сравнить центровку.
