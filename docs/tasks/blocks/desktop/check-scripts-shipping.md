# Поставлять скрипты проверки вместе с установщиком

**Статус** — ✅ Выполнена

**Основание** — [Изоляция сбоя](../../core/plugin-failure-isolation.md) · [Метрики](../../core/action-metrics.md) · [Чек-лист Windows](../../../windows-acceptance.md)

## Наблюдение

После установки 0.4.5 в `D:\Util Maker` лежит только `measure-windows.ps1`
старой копии. `scripts\kill-plugin.ps1` отсутствует. В чек-листе проверки
указаны оба скрипта, но установщик их не копирует.

## Ожидаемое поведение

- Установщик кладёт `measure-windows.ps1` и `kill-plugin.ps1` в каталог
  установки или отдельный `scripts`.
- Пути в чек-листе совпадают с фактическим расположением.
- Скрипты не требуют запуска из репозитория.

## Критерии приёмки

- [ ] Оба скрипта входят в установщик.
- [ ] `measure-windows.ps1 -InvokeBenchmark -InvokeCount 50` запускается из
  каталога установки.
- [ ] `kill-plugin.ps1` запускается до вызова действия и завершает процесс.
- [ ] Чек-лист ссылается на фактические пути.

## Проверка

Чистая установка Windows: проверить наличие обоих файлов и выполнить команды
из каталога установки.

0.4.6: в `D:\Util Maker\scripts` установлены `kill-plugin.ps1` и обновлённый `measure-windows.ps1`.
