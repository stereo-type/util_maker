# Дать выбор чистой установки и открывать настройки после установки

**Статус** — ✅ Выполнена

**Основание** — [Установка для Windows](../../../../installer/README.txt) · [Первая поставка](../../../roadmap.md)

## Наблюдение

Установщик всегда сохранял профиль, поэтому после проверок с удалёнными
плагинами и изменёнными сочетаниями нельзя было получить чистое состояние.
Галочка «Запустить» запускала хост в трей, и пользователь не видел настроек.

## Что сделано

- На странице параметров установщика добавлен чекбокс «Чистая установка:
  удалить сочетания, настройки плагинов и установленные пакеты».
- По умолчанию чекбокс снят — обычное обновление сохраняет профиль.
- Перед подтверждением показывается предупреждение о необратимости.
- При чистой установке удаляются `%LOCALAPPDATA%\org.utilmaker.prototype` и
  журнал `%LOCALAPPDATA%\Util Maker\logs`; пакеты поставки затем ставятся заново.
- Галочка «Запустить Util Maker» вызывает приложение с `--open-settings`;
  хост открывает настройки, а не сворачивается в трей.

## Проверка

- Windows 0.4.11: запуск с `--open-settings` открывает окно настроек;
- обычная silent-установка профиль не удаляет;
- NSIS собирается без предупреждений, установщик 0.4.11 сформирован.

## Критерии приёмки

- [x] Установщик спрашивает про чистую установку.
- [x] Без галочки настройки, сочетания и пакеты сохраняются.
- [x] С галочкой профиль сбрасывается, пакеты ставятся заново.
- [x] Запуск после установки открывает настройки.
