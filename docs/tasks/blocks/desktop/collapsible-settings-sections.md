# Сворачивать разделы настроек до заголовка

**Статус** — 👁️ На ревью

[ТЗ интерфейса и настроек](../../../blocks/desktop/settings.md) · [Стиль интерфейса](../../../ui-style-guide.md)

## Наблюдение

Окно настроек (`apps/desktop/ui/index.html`) показывает все разделы сразу: «Микроприложения», «Установка пакета», «Запуск» и блок с путями журнала и состояния. У последнего блока нет заголовка — только `dl`. Из-за этого установка пакета и служебные пути занимают место на старте, хотя в обычной работе нужен список микроприложений.

## Ожидаемое поведение

1. Каждый раздел — сворачиваемая карточка: в свёрнутом виде остаётся одна строка заголовка с названием и стрелкой справа.
2. По умолчанию развёрнут только «Микроприложения». «Установка пакета», «Запуск» и «Журнал и состояние» свёрнуты.
3. Четвёртый блок получает заголовок «Журнал и состояние» и становится таким же разделом.
4. Вся строка заголовка нажимается: текст, пустое место и стрелка переключают состояние; курсор pointer, наведение заметно.
5. Стрелка справа показывает состояние: вправо — свёрнуто, вниз — развёрнуто; поворот на 90°, при `prefers-reduced-motion: reduce` без анимации.
6. Состояние семантическое: кнопка с `aria-expanded` и `aria-controls` либо нативный `<details>`; в свёрнутом виде содержимое скрыто и не попадает в Tab; стрелка декоративная.
7. С клавиатуры: Tab ставит фокус на заголовок, Enter и Space переключают, кольцо фокуса видно; стрелка не отдельная цель Tab.
8. Разделы независимы: можно открыть несколько; раскрытие одного не закрывает другие.
9. Содержимое не теряет состояние при сворачивании: введённые поля, результаты проверки, чекбокс автозапуска.
10. После закрытия и нового открытия настроек снова развёрнут только «Микроприложения»: окно создаётся заново.
11. Заголовки не обрезаются и не заходят на стрелку при 100, 150 и 200%; цель нажатия не меньше 32×32 px.
12. Нижние кнопки «Закрыть настройки»/«Выход», подпись и прокрутка работают как раньше.

## Критерии приёмки

- [x] При открытии «Микроприложения» развёрнуты, остальные три показывают только заголовки.
- [x] Клик по заголовку и по стрелке переключает раздел; стрелка меняет направление.
- [x] Tab обходит заголовки, Enter и Space переключают, фокус виден; скринридер сообщает название и состояние.
- [x] Несколько разделов можно открыть одновременно; они не влияют друг на друга.
- [x] Введённые значения и результаты не теряются при сворачивании и раскрытии.
- [x] После закрытия и повторного открытия настроек снова развёрнут только «Микроприложения».
- [x] На 100/150/200% заголовки и стрелка не обрезаются; цель нажатия не меньше 32×32.
- [x] Оформление карточек, отступы и поведение модальных окон не изменились; `alert/confirm/prompt` нет.

## Зависимости

**Для старта** — можно начинать на текущей ревизии.

**Для сквозной проверки** — Windows 11: масштабы 100/150/200%, клавиатура, Narrator при возможности. Отдельных карточек не требуется.

## Что учесть

- Четвёртому блоку нужен заголовок и `aria-labelledby` у `section`; сейчас у него нет `h2`.
- Заголовок — один интерактивный элемент: не вкладывать кнопки и ссылки. Кнопка на всю ширину, `justify-content: space-between`, стрелка через `svg` или CSS.
- Свёрнутое содержимое прятать `hidden`/`display:none`, а не прозрачностью: иначе Tab попадёт в поля.
- Модальное окно плагина лежит внутри раздела «Микроприложения». Оно открывается только при развёрнутом разделе; при переносе разметки сохранить закрытие, фокус-ловушку и возврат фокуса.
- Не переименовывать существующие ID (`plugin-list`, `package-result`, `autostart` и другие): на них завязаны команды и drag-and-drop.
- Обновить [ТЗ интерфейса и настроек](../../../blocks/desktop/settings.md): перечислить разделы, умолчания и клавиатурное поведение.

## Что сделано

- Все четыре раздела — нативные `<details>/<summary>` с общим стилем карточки. По умолчанию открыт только «Микроприложения».
- Четвёртый блок получил заголовок «Журнал и состояние», `section` — `aria-labelledby="diagnostics-title"`. Существующие ID не менялись.
- Вся строка заголовка — одна цель нажатия высотой 48 px: текст, пустое место и SVG-стрелка. Стрелка декоративная, поворачивается на 90°, при `prefers-reduced-motion: reduce` анимация отключена.
- Tab/Enter/Space и `expanded` работают через нативную семантику `summary`; фокус-кольцо не обрезается карточкой. Свёрнутое содержимое браузер исключает из Tab.
- Состояние полей и результатов не теряется: содержимое не удаляется из DOM. Разделы независимы, модальное окно плагина осталось внутри первого раздела.
- Обновлено [ТЗ интерфейса и настроек](../../../blocks/desktop/settings.md): разделы, умолчания, клавиатура и сохранение состояния.

## Проверка

Linux, ревизия `f34be6c`, версия `0.4.30`:

- `node --check` для встроенного скрипта — без ошибок.
- Разметка: стек HTML сбалансирован; 4 раздела, 1 `open`, 4 заголовка с корректными `aria-labelledby`, 4 декоративные стрелки; обязательные ID (`plugin-list`, `package-result`, `autostart` и другие) на месте.
- Chromium 156 headless через DevTools Protocol — **36/36** проверок:
  - старт: открыт только первый раздел, порядок заголовков и `aria-labelledby` совпадают;
  - Tab: первый → второй → третий заголовок, скрытые поля пропускаются, `:focus-visible` и рамка 2 px;
  - Enter и Space переключают; accessibility tree отдаёт `DisclosureTriangle` с именем «Установка пакета» и `expanded=true/false`;
  - клик по заголовку и SVG-стрелке переключает раздел, стрелка поворачивается вниз;
  - путь пакета сохраняется после сворачивания и раскрытия; одновременно открыты 2 и 3 раздела;
  - 760/507/380 px (эквивалент 100/150/200% ширины окна): нет горизонтального скролла, заголовок не заходит на стрелку, цель ≥32 px;
  - после перезагрузки снова открыт только «Микроприложения»; модальное окно осталось в первом разделе; `alert/confirm/prompt` нет.
- Модальное окно плагина в headless Chromium — **5/5**: открывается, фокус на «Закрыть», Esc закрывает, фокус возвращается на «Открыть», Tab зациклен внутри окна.
- `make check` — версия согласована, rustfmt и Clippy без замечаний, **261 тест** пройден в 37 наборах, ошибок нет.

Windows, остаётся визуальная и Narrator-проверка:

- Ревизия `f34be6c`, команда `make build-windows`, установить `dist/UtilMaker-Setup-0.4.30-dev.exe`.
- Открыть настройки: развёрнуты только «Микроприложения», остальные три показывают только заголовки.
- Кликнуть по тексту заголовка, пустому месту и стрелке; открыть несколько разделов. Ввести путь пакета, свернуть и раскрыть — значение должно сохраниться.
- Пройти Tab/Enter/Space; Narrator должен сообщать название раздела и состояние «развёрнуто/свернуто».
- Повторить при 150% и 200%: заголовки не обрезаются, стрелка не наезжает на текст, цель нажатия удобна.
