# Защищать контрольный модуль и восстанавливать пакеты поставки

**Статус** — ✅ Выполнена

**Основание** — [Пакеты поставки](../../packages/bundled-packages-bootstrap.md) · [Управление пакетами](package-management.md)

## Наблюдение

Контрольный модуль можно было удалить через «Удалить пакет». После этого
`Ctrl+Shift+U` переставал работать, а `bundled-packages-v1` не давал
установщику повторно поставить пакеты поставки. В каталоге `packages` при этом
лежали только `screenshot` и `translator`, поэтому контрольный модуль не
восстанавливался.

## Что сделано

- `remove_package` отклоняет удаление `org.utilmaker.control`.
- В окне контрольного модуля кнопка «Удалить пакет» заменена пояснением, что
  модуль входит в ядро.
- `bootstrap_bundled_packages` больше не выходит сразу по маркеру: при каждом
  запуске выбирает последнюю версию каждого `.umpkg` в `packages` и
  идемпотентно устанавливает её.
- Удалённые `screenshot`/`translator` восстанавливаются при следующем запуске.

## Проверка

- Windows 0.4.10: в окне контроля нет «Удалить пакет», есть пояснение.
- `cargo test -p util-maker-packages` — 23/23.
- Запуск после установки: пакеты поставки снова в профиле, сочетания
  зарегистрированы.
