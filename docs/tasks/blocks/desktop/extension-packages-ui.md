# Показывать плагины-расширения на странице микроприложения

**Статус** — ✅ Выполнена

[ТЗ desktop-хоста](../../../blocks/desktop/README.md) · [ТЗ интерфейса и настроек](../../../blocks/desktop/settings.md) · [Контракт плагинов-расширений](../../../blocks/core/extensions.md)

Добавить на страницу микроприложения раздел «Плагины»: список точек
расширения, выбор активного плагина, установка, настройка, отключение и
удаление. Пакет-расширение не должен выглядеть отдельным микроприложением,
если у него нет собственных действий.

**Зависимости для старта** — [Подключать и вызывать плагины-расширения](../core/nested-extensions.md), [Устанавливать пакеты-расширения](../packages/extension-packages.md).

**Для сквозной проверки** — [Перевести переводчик на провайдеров-плагинов](../plugins/translator/provider-extension-point.md), [Поставлять Яндекс и Google отдельными плагинами](../plugins/translator/providers/provider-packages.md).

## Критерии приёмки

- [x] На странице родителя видны его точки расширения, активный плагин и доступные вклады. Для `single` выбор переключается без перезапуска и действует на следующий вызов.
- [x] Для обязательной точки без активного плагина показан статус «Нужна настройка» с понятным следующим действием; вызов родителя показывает эту причину, а не падает общей ошибкой.
- [x] Установка плагина из раздела использует общий диалог `.umpkg` и показывает родителя, точку и контракт до подтверждения. После успешной установки вклад появляется в списке без перезапуска.
- [x] «Настроить» открывает форму плагина по его `settings`; секреты и команда проверки подключения относятся только к этому плагину. Родитель и другой плагин не видят его значений.
- [x] «Отключить» скрывает вклад и освобождает выбор, сохраняя пакет и настройки. «Удалить» очищает настройки и секреты плагина, но оставляет родителя и другие вклады.
- [x] Плагин без родителя или с несовместимым контрактом виден в менеджере пакетов с причиной неактивности и ссылкой на нужного родителя. Обычный список микроприложений не дублирует extension-only пакет.
- [x] Раздел проходит с клавиатуры, показывает текстовые статусы и работает при 100%, 150% и 200% масштабе. Ошибки установки и выбора остаются рядом с соответствующим элементом.

## Что сделано

- На странице микроприложения появился раздел «Плагины»: точки расширения, активный вклад, выбор для `single`, установка, настройка, отключение и удаление.
- Управление сделано списком: одна строка на плагин — радиокнопка выбора активного, название, статус («активен», «выключен», «недоступен: причина») и одно меню «⋯» с действиями «Настроить», «Включить/Отключить», «Удалить». Это масштабируется на десяток провайдеров и убирает простыню кнопок.
- Меню закрывается по клику мимо, Esc, прокрутке и перерисовке раздела; фокус переходит на первый пункт, Tab ходит внутри меню, Esc возвращает фокус на кнопку.
- «Установить плагин» закрывает карточку микроприложения, раскрывает раздел «Установка пакета» на странице настроек и ставит фокус в поле пути, а не прокручивает скрытую под модальным окном страницу.
- Для обязательной точки без выбора показан статус «Нужна настройка»; кнопка «Установить плагин» ведёт к общему диалогу `.umpkg`.
- Пакеты-расширения без действий вынесены в отдельный раздел менеджера с родителем, точкой, контрактом и причиной неактивности.
- Настройки плагина открываются его собственной страницей и используют его `settings` и секреты.

## Проверка

Linux: `make check`, тесты команд desktop и модели состояния страницы с
подготовленным каталогом пакетов: выбор, установка, отключение, удаление,
отсутствующий родитель, несовместимый контракт, ошибка сохранения. Frontend
собирается только по явной просьбе пользователя.

Windows: на ревизии из карточки собрать `make build-windows` и проверить:

- установить переводчик и оба плагина провайдеров;
- выбрать Яндекс, открыть его настройки, ввести ключ и проверить подключение;
- переключиться на Google и повторить вызов тем же шорткеем;
- отключить один плагин, убедиться, что второй и переводчик работают;
- удалить плагин и проверить, что его ключ больше не используется;
- пройти выбор и установку с клавиатуры при трёх масштабах.

Windows 0.4.35: пользователь подтвердил установку Яндекса и Google, выбор активного провайдера, настройку, отключение и удаление, а также новый список «Плагины» с меню действий.
