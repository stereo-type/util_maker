# Заменить браузерные JS-алерты на модальные окна приложения

**Статус** — 📥 К выполнению

**Основание** — [Стиль интерфейса](../../../ui-style-guide.md) · [Конфликт сочетаний](../../core/settings-conflict.md)

## Наблюдение

При переносе занятого сочетания показывается системный браузерный
`window.confirm` — чужой, некрасивый диалог. Такие алерты запрещены в
приложении. Аналогичные `alert`/`confirm`/`prompt` могут быть в других местах.

## Ожидаемое поведение

- Никаких `window.alert`, `window.confirm`, `window.prompt`.
- Подтверждение переноса сочетания — модальное окно в стиле приложения:
  заголовок, причина, кнопки «Перенести» / «Отмена».
- Окно по центру, с фокусом, Tab внутри, Esc = отмена.
- Ошибки и подтверждения используют один компонент.
- Кнопки называют последствие, а не «ОК».

## Критерии приёмки

- [ ] В коде UI нет `alert`, `confirm`, `prompt`.
- [ ] Перенос сочетания подтверждается модальным окном приложения.
- [ ] «Отмена» оставляет прежние привязки, «Перенести» забирает сочетание.
- [ ] Окно центрировано, доступно с клавиатуры, Esc работает.
- [ ] Ошибки/подтверждения используют общий стиль.

## Проверка

Windows: назначить занятое сочетание, проверить внешний вид, отмену и перенос;
поиском по UI-коду убедиться в отсутствии браузерных алертов.
