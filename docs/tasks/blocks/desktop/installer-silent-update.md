# Исправить silent-обновление установщика

**Статус** — 📥 К выполнению

**Основание** — [Установка Windows](../../../installer/README.txt) · [Распространение](../windows-distribution.md)

## Наблюдение

Установщик 0.4.24 с `/S` завершается с кодом 0, но файлы не обновляются:
`util-maker-desktop.exe` остаётся от 0.4.23, каталог
`modules\org.utilmaker.control` отсутствует. GUI-установщик открывается.

## Ожидаемое поведение

- `/S` обновляет exe и модули до версии установщика.
- Контрольный модуль всегда устанавливается/восстанавливается.
- Повторный silent-запуск идемпотентен.
- Код возврата отражает реальную ошибку.

## Критерии приёмки

- [ ] `/S` обновляет `util-maker-desktop.exe` и `modules\org.utilmaker.control`.
- [ ] Версия в журнале совпадает с установщиком.
- [ ] После установки хост запускается и видит три модуля.
- [ ] Повторный запуск не ломает профиль.

## Проверка

Windows: установить `/S` поверх 0.4.23, проверить exe, control-модуль, журнал.
