# Подключить редактор и глобальные клавиши к общему реестру

**Статус** — ✅ Выполнена

[Этап 2 плана развития](../../../roadmap.md#2-устанавливать-и-обновлять-инструменты-из-настроек) · [ТЗ блока](../../../blocks/desktop/settings.md)

Заменить `HotkeyDemo`, фиктивную регистрацию и отдельный маршрут контрольного сочетания связкой постоянного реестра, `HotkeyService` и активных действий. Сохранить существующий интерфейс подтверждения.

**Зависимости для старта** — [Строить трей и список микроприложений по активным манифестам](action-menu.md), [Сохранять привязки всех действий при изменении состава пакетов](../core/persistent-shortcuts.md).

## Критерии приёмки

- [ ] Предварительная проверка и сохранение работают по актуальным данным. При внутреннем конфликте показаны оба владельца и доступны отмена и перенос, при системном или внешнем отказе сохранение запрещено.
- [ ] Назначенное сочетание маршрутизирует один вызов нужному действию. Пауза и отключение освобождают системную регистрацию. Повторное включение показывает новый внешний конфликт, остальные действия работают.
- [ ] Редактор позволяет искать привязки, добавить несколько сочетаний действию, удалить одно и восстановить рекомендованное через общие правила.

## Проверка

На Linux через `make test` проверить связку команд с подменной ОС. Пользователь на Windows переносит сочетание со скриншота на переводчик, проверяет Win+L, чужую регистрацию и удержание клавиши.

## Что уже сделано

- `ShortcutRuntime` хранит регистрации всех активных действий, а не только контрольного.
- При старте и обновлении каталога регистрируются рекомендованные сочетания скриншотов и переводчика.
- `WM_HOTKEY` маршрутизируется по ID в нужное действие.
- Пауза снимает все регистрации, возобновление возвращает их.
- Отключение/удаление модуля освобождает его регистрации.

## Что осталось

- Редактор для любого действия: поиск, несколько сочетаний, удаление и восстановление рекомендованного.
- Показ владельцев внутреннего конфликта и переноса в UI.
- Постоянное хранение всех привязок через `HotkeyRegistry`.

## Новые возможности

- Несколько сочетаний на одно действие; добавление, удаление и сброс к рекомендованному.
- Поиск по названию действия/описанию/сочетанию.
- Все привязки сохраняются в `shortcuts.json` и восстанавливаются после перезапуска.
- При конфликте показывается владелец и предлагается перенос; отмена оставляет прежнее.
- Системные и внешние конфликты обрабатываются платформенной регистрацией.

## Проверка

Linux: Clippy, сборка, JavaScript. Windows: назначить два сочетания действию, удалить одно, сбросить, перенести сочетание между действиями, проверить паузу и перезапуск.
