# Открывать overlay скриншота на весь виртуальный экран

**Статус** — 📥 К выполнению

**Основание** — [Редактор области](../plugins/screenshot/region-editor.md)

## Наблюдение

На Windows 0.4.5 при вызове «Снять область» открывается окно `Снять область`
небольшим окном справа, а не поверх всего рабочего стола. Снимок виртуального
экрана 6000×1440 (левый монитор 2560×1440, основной 3440×1440), но overlay не
перекрывает ни один монитор целиком — выделить область мышью невозможно.

Вероятная причина: `WebviewWindowBuilder::position`/`inner_size` получают
логические координаты, а захват и виртуальный экран — физические; отрицательный
`x` второго монитора и масштаб DPI дают неверную геометрию.

## Ожидаемое поведение

- Overlay занимает весь виртуальный рабочий стол, включая монитор слева с
  отрицательным `x`.
- Захваченное изображение совпадает с экраном; панель инструментов не входит в
  результат.
- Окно без рамки, поверх остальных, не показывается в панели задач.

## Критерии приёмки

- [ ] Позиция и размер окна задаются в физических пикселях.
- [ ] На конфигурации 2560×1440 слева + 3440×1440 справа overlay покрывает оба
  монитора.
- [ ] Выделение и копирование работают на обоих мониторах.
- [ ] Повторный вызов не создаёт второе окно.

## Проверка

Windows с двумя мониторами и разным DPI: открыть «Снять область», проверить
покрытие, выделить область на левом мониторе и на стыке.
