# Убрать дублирование названия и версии на странице микроприложения

**Статус** — 📥 К выполнению

[Этап 2 плана развития](../../../../roadmap.md#2-устанавливать-и-обновлять-инструменты-из-настроек) · замечание к [«Строить трей и список микроприложений по активным манифестам»](action-menu.md)

## Наблюдение

После открытия микроприложения его название, версия и состояние повторяются вторым блоком сразу под строкой списка. Пользователь уже видит, какой модуль открыт и включён ли он.

## Критерии приёмки

- [ ] На странице микроприложения один заголовок с названием; версия и состояние показаны один раз.
- [ ] Дублирующий блок удалён, действия и результат остаются на месте.
- [ ] Переход между списком и страницей не меняет высоту и ширину контента скачком.
- [ ] Страница остаётся доступной с клавиатуры.
