## Критерии приёмки

- [ ] Виден тип, сервис, реализации и состояния пакетов. Доступны установка, включение, отключение и переход к настройке. Перечисление не запускает процессы и сеть.
- [ ] Можно добавить два аккаунта одного сервиса, проверить соединение, переименовать, повторно войти и удалить один. Форма строится по метаданным реализации. Пароли и значения токенов обратно не показываются.
- [ ] Диалог удаления перечисляет затронутые приложения. Остальные аккаунты и папки остаются доступны. Пустое состояние, ошибки, Tab, Esc и возврат фокуса соответствуют стилю приложения.

## Проверка

Linux, проверка переходов и команд на тестовом хосте. На Windows пользователь выполняет полный цикл добавления и удаления второго аккаунта.
