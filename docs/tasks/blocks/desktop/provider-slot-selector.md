## Критерии приёмки

- [ ] Приложения без слота не получают поле. Для объявленного слота предлагаются только совместимые установленные сервисы и их именованные подключения. Пустое состояние ведёт к установке или подключению.
- [ ] Выбор папки делегируется контракту типа. Сохранение меняет только `(consumerId, slotId)`. Изменение имени аккаунта и переход между приложениями не сбрасывают назначения.
- [ ] Отключённое или удалённое назначение явно помечено. Экран не выбирает автоматически другой аккаунт, позволяет восстановить или сменить привязку.

## Проверка

Linux, тестовые манифесты двух типов, два потребителя с разными папками и два одноимённых каталога. Windows, клавиатура и восстановление настроек после перезапуска.
