# Восстанавливать трей и регистрации после смены состояния сессии

**Статус** — 📥 К выполнению

[Этап 4 плана развития](../../../roadmap.md#4-принять-первую-поставку-windows) · [ТЗ блока](../../../blocks/desktop/README.md)

Провести события сна, разблокировки и перезапуска Explorer от адаптера Windows до работающего трея и реестра. Проверить также штатный выход приложения во время действия.

**Зависимости для старта** — [Подключить редактор и глобальные клавиши к общему реестру](live-shortcuts.md).

## Критерии приёмки

- [ ] После восстановления доступен один трей. Доступные сочетания зарегистрированы один раз, для уже занятого показана причина. Пользовательская пауза сохраняется.
- [ ] Выход прекращает приём новых команд, отменяет текущие вызовы и освобождает сочетания. После повторного запуска действия доступны.

## Проверка

На Linux проверить повторную доставку событий с подменным адаптером. Пользователь на Windows проверяет сон, разблокировку и восстановление после перезапуска Explorer.
