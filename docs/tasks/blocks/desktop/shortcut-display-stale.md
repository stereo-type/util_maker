# Показывать новое сочетание после сохранения

[Этап 2 плана развития](../../../../roadmap.md#2-устанавливать-и-обновлять-инструменты-из-настроек) · замечание к [«Сохранять привязки при изменении состава пакетов»](../core/persistent-shortcuts.md)

## Наблюдение

Пользователь меняет сочетание контрольного модуля, сохраняет без ошибки. Новое сочетание сразу работает и переживает перезапуск, но в интерфейсе рядом с действием по-прежнему показано старое. После перезапуска отображение остаётся неверным.

То есть запись и регистрация работают, а слой состояния/перерисовки показывает устаревшую привязку.

## Критерии приёмки

- [ ] После успешного сохранения список и страница действия показывают новое сочетание без перезапуска.
- [ ] Старое сочетание исчезает из интерфейса и больше не отображается как активное.
- [ ] После перезапуска отображается то же сочетание, которое реально зарегистрировано.
- [ ] При ошибке сохранения интерфейс оставляет прежнее сочетание и показывает причину.
- [ ] Обновление списка не запускает процессы плагинов.
