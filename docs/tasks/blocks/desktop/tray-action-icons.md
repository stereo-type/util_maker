# Добавить иконки действиям в меню трея

**Статус** — 📥 К выполнению

[Этап 2 плана развития](../../../../roadmap.md#2-устанавливать-и-обновлять-инструменты-из-настроек) · замечание к [«Строить трей и список микроприложений по активным манифестам»](action-menu.md)

## Наблюдение

Меню трея содержит только текстовые пункты действий. Для наглядности нужны небольшие иконки, как в меню других резидентных приложений (пример — меню Телемоста).

## Критерии приёмки

- [ ] Каждый пункт действия в меню трея имеет иконку из манифеста или нейтральную заглушку.
- [ ] Служебные пункты (настройки, пауза, выход) также имеют различимые иконки.
- [ ] Иконки читаются в светлой и тёмной теме Windows.
- [ ] Пункт без иконки не ломает меню и остаётся доступным по тексту.
