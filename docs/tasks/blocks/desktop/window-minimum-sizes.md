# Задать минимальные размеры всем окнам и модалкам

**Статус** — 📥 К выполнению

[ТЗ интерфейса и настроек](../../../../blocks/desktop/settings.md) · [Стиль интерфейса](../../../../ui-style-guide.md)

## Наблюдение

Окна приложения открываются слишком маленькими для своего содержимого. В окне результата QR-код наезжает на подпись и кнопки, текст и поле ввода обрезаются; окно настроек 700×620 при 150–200 % масштабе показывает только часть формы, а модальное окно микроприложения занимает почти весь экран и всё равно прокручивается. Минимальные размеры заданы только у настроек (560×460), у остальных окон ограничения нет или оно меньше содержимого.

Список окон, которые нужно проверить: настройки, модальное окно микроприложения, окно результата действия, окно результата QR, редактор снимка, модальное окно сочетания, окно подтверждения, окно выбора цвета пикселя.

## Ожидаемое поведение

1. У каждого окна и модалки есть минимальный размер, при котором всё содержимое читается без наложения и обрезания: заголовок, основные поля, кнопки и подписи.
2. Минимальный размер учитывает масштаб 100, 150 и 200 %: при увеличении включается прокрутка внутри окна, а кнопки действий остаются доступны.
3. Окно результата растёт под содержимое: длинный текст, QR-код и кнопки не перекрывают друг друга. Для QR окно не меньше, чем нужно панели с QR и полю текста.
4. Модальные окна не выходят за рабочую область монитора и не открываются больше неё; на маленьком мониторе размер уменьшается до рабочей области с прокруткой.
5. Минимальные размеры не мешают перетаскиванию и изменению размера там, где оно разрешено; окно не «прыгает» при открытии.
6. Для каждого окна зафиксированы значения по умолчанию и минимум; они проверены на мониторах 1920×1080 и 3440×1440 при 100/150/200 %.

## Критерии приёмки

- [ ] Настройки: при 560×460 и при 200 % ничего не обрезается, форма прокручивается, кнопки «Закрыть настройки» и «Выход» доступны.
- [ ] Модальное окно микроприложения: заголовок, поиск, действия и настройки видны при минимальном размере; прокрутка не прячет кнопки.
- [ ] Окно результата: текст, метаданные и кнопки не наезжают друг на друга; минимальный размер вмещает две строки текста и все кнопки.
- [ ] Окно результата QR: QR-код целиком помещается в своей рамке, не перекрывает подпись, поле текста и кнопки; окно можно увеличить.
- [ ] Редактор снимка, окно сочетания, подтверждение и выбор цвета: содержимое не обрезается при минимальном размере.
- [ ] На мониторе 1920×1080 при 200 % модалки не выходят за рабочую область.
- [ ] `make check` проходит, для новых ограничений добавлены проверки разметки/скриптов, где это возможно.

## Зависимости

**Для старта** — можно начинать на текущей ревизии.

**Для сквозной проверки** — Windows 11: мониторы 1920×1080 и 3440×1440, масштабы 100/150/200 %. Отдельных карточек не требуется.

## Что учесть

- Размеры задаются в `apps/desktop/src/main.rs` (`WebviewWindowBuilder::inner_size`, `min_inner_size`) и в CSS модалок `apps/desktop/ui/index.html`; для редактора — в `editor_placement`.
- `show_result` сейчас переиспользует окно и не пересчитывает минимальный размер при смене типа результата (текст → QR и обратно).
- Панель QR в `result.html` должна прокручиваться вместе с окном, а не выходить за него; проверить `overflow` и `aspect-ratio`.
- Не увеличивать окна больше рабочей области монитора: ограничение сверху берётся из `ScreenGeometry`.
- После правок проверить, что центр окна и позиция на активном мониторе не сломались.
