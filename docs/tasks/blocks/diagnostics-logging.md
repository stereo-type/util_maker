# Записать сбой действия без пользовательских данных

**Статус** — К выполнению

**Основание** — [ТЗ блока «Диагностика»](../../blocks/diagnostics.md).

Реализовать структурированный локальный журнал с ротацией. Проверку выполнить на искусственных ошибках IPC и HTTP с контрольными значениями.

## Критерии приёмки

- [ ] По записи можно определить версию, модуль, действие, длительность и код ошибки.
- [ ] Ключ, заголовок авторизации, URL с секретом, исходный текст, перевод и данные буфера отсутствуют в сформированном журнале.
- [ ] При достижении настроенного порога файл ротируется, следующее событие доступно в текущем журнале.
