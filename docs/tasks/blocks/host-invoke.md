# Вызвать действие контрольного модуля через IPC

**Статус** — К выполнению

**Основание** — [ТЗ блока «Ядро»](../../blocks/host.md).

Провести один invoke от пары moduleId и actionId до handler в дочернем процессе. Начать с тестового транспорта. Для сквозной проверки подключить [handshake SDK](module-sdk-handshake.md).

## Критерии приёмки

- [ ] Из теста на Ubuntu запускается контрольный процесс и возвращает результат с ID вызова.
- [ ] Аварийное завершение дочернего процесса завершает вызов ошибкой. Повторный вызов успешен.
- [ ] После отмены поздний ответ игнорируется, зависший процесс завершается в пределах 2 с.
