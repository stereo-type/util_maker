# Передать занятое сочетание другому действию

**Статус** — К выполнению

**Основание** — [ТЗ блока «Шорткеи»](../../blocks/hotkeys.md).

Реализовать перенос назначения в переносимом ядре. Подставить тестовый адаптер ОС и хранилище, чтобы воспроизвести системный отказ и ошибку записи.

## Критерии приёмки

- [ ] Проверка называет обоих владельцев. Отмена сохраняет обе привязки, включая привязку отключённого модуля.
- [ ] После подтверждения и повторного открытия хранилища сочетание принадлежит новому действию. Остальные назначения сохранены.
- [ ] Системный запрет, сбой записи и устаревшее подтверждение предотвращают перенос.
