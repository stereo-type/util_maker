# Согласовать версию API при запуске модуля

**Статус** — К выполнению

**Основание** — [ТЗ блока «SDK»](../../blocks/module-sdk.md).

Реализовать initialize для SDK и контрольного модуля. За основу взять IPC из раздела 4 общего ТЗ. Проверить обмен на Ubuntu через stdin/stdout.

## Критерии приёмки

- [ ] Совместимая версия проходит handshake за отведённые 3 с.
- [ ] Несовместимая версия, повреждённый JSON и ответ после таймаута дают различимые ошибки.
- [ ] Диагностика контрольного процесса не попадает в stdout с JSON-RPC.
