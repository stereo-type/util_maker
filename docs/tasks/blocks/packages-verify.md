# Проверить локальный пакет до установки

**Статус** — На ревью

**Основание** — [ТЗ блока «Пакеты»](../../blocks/packages.md).

Прочитать манифест и проверить подпись, хеши, издателя, платформу и диапазон API до активации. Подготовить локальные подписанные тестовые пакеты.

## Критерии приёмки

- [x] Корректный пакет возвращает сведения для предварительного просмотра без запуска модуля.
- [x] Изменённая нагрузка, чужая подпись или несовместимый API отклоняются с причиной.
- [x] Абсолютный путь, выход за каталог и ссылка наружу отклоняются. Активная версия остаётся доступной.

## Что сделано

- [Формат `.umpkg`](../../package-format.md): ZIP с `manifest.json`, отсоединённой подписью Ed25519 и списком `files` с SHA-256.
- `crates/packages` — `TrustStore`, `PackagePreview`, `verify_path`/`verify_reader`. Проверка читает архив потоком, не распаковывает его и не запускает модуль.
- Отклоняются: неизвестный издатель, неверная подпись, несовместимый `hostApi`, отсутствующая точка входа платформы, изменённый файл, лишний файл, абсолютный путь, `..`, обратные слэши, буква диска и символическая ссылка.
- Манифест получил необязательное поле `files`; существующие модули без него остаются совместимыми.

## Проверка

Linux, контейнер `util-maker-dev:local`:

- `make test` — 45 тестов, в том числе 7 тестов пакетов:
  - корректный подписанный пакет возвращает ID, имя, версию, действия, точку входа и суммарный размер без запуска модуля;
  - изменённая нагрузка даёт `HashMismatch`;
  - подпись чужим ключом даёт `InvalidSignature`;
  - `hostApi >=2.0.0 <3.0.0` при хосте 1.0.0 даёт `IncompatibleApi`;
  - абсолютный путь, `../` и `bin/../../module.exe` дают `UnsafePath`;
  - неизвестный издатель и лишний файл отклоняются;
  - после неудачной проверки ранее сформированный активный preview остаётся доступным.
- `make lint` — Clippy без предупреждений, `make fmt` — без изменений.
