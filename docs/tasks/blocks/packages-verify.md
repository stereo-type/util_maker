# Проверить локальный пакет до установки

**Статус** — К выполнению

**Основание** — [ТЗ блока «Пакеты»](../../blocks/packages.md).

Прочитать манифест и проверить подпись, хеши, издателя, платформу и диапазон API до активации. Подготовить локальные подписанные тестовые пакеты.

## Критерии приёмки

- [ ] Корректный пакет возвращает сведения для предварительного просмотра без запуска модуля.
- [ ] Изменённая нагрузка, чужая подпись или несовместимый API отклоняются с причиной.
- [ ] Абсолютный путь, выход за каталог и ссылка наружу отклоняются. Активная версия остаётся доступной.
