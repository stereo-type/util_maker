# Экспортировать подписанный пакет .umpkg

**Статус** — 📥 К выполнению

**Основание** — [ТЗ менеджера пакетов](../../../blocks/packages/README.md) и [формат .umpkg](../../../blocks/packages/package-format.md).

Разработчик может собрать из подготовленного каталога плагина, включая собранную точку входа, архив для передачи пользователю. Архив должен приниматься существующим проверяющим кодом. Экспорт работает без запуска хоста и установки пакета.

**Зависимости для старта** — существующие парсер манифеста и проверка пакета. Для приёмки использовать временный ключ и подготовленный каталог с манифестом контрольного плагина. Можно начать до появления процессов штатных плагинов.

## Критерии приёмки

- [ ] В [инструкции по формату](../../../blocks/packages/package-format.md) описана цель Makefile для экспорта с исходным каталогом, выходным файлом и способом передачи ключа издателя. Закрытый ключ остаётся за пределами пакета и журнала.
- [ ] Экспорт добавляет хеши SHA-256 полезной нагрузки в манифест и подписывает итоговые байты Ed25519. Существующая проверка принимает архив с соответствующим доверенным ключом и возвращает ожидаемые ID, версию и точку входа.
- [ ] Отсутствующая точка входа и попытка включить файл вне исходного каталога приводят к отказу. При неудачном экспорте ранее созданный выходной файл остаётся пригодным к проверке.
- [ ] Проверки выполняются на Linux. Установка архива и подключение команды к desktop-интерфейсу могут разрабатываться отдельно.

## Проверка

Заполняется при передаче на ревью.
