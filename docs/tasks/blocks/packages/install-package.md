# Установить проверенный пакет в профиль пользователя

**Статус** — 📥 К выполнению

[Этап 2 плана развития](../../../roadmap.md#2-устанавливать-и-обновлять-инструменты-из-настроек) · [ТЗ блока](../../../blocks/packages/README.md)

Расширить `crates/packages`: после предварительного просмотра и подтверждения сохранить подписанное содержимое в каталог версии и опубликовать активную запись. Начать можно с уже используемых в тестах подписанных архивов.

**Зависимости для старта** — можно начинать на текущей ревизии.

**Для сквозной проверки** — [Экспортировать подписанный пакет .umpkg](export-package.md).

## Критерии приёмки

- [ ] На чистом профиле после установки и повторного открытия хранилища доступны ID, версия, манифест, состояние и путь к исполняемому файлу. Чтение каталога не запускает модуль.
- [ ] Существующая проверка подписи, издателя, API, платформы и путей применяется к тем же байтам, которые распаковываются. Повреждение или ошибка записи не публикует частичную установку.
- [ ] Повторная установка тех же байтов даёт одну запись. Попытка заменить уже известный ID другим издателем отклоняется.

## Проверка

На Linux через `make test` установить пакет во временный профиль, повторно открыть его, затем подменить содержимое и воспроизвести ошибку записи.
