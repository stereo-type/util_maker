## Критерии приёмки

- [ ] Предпросмотр распознаёт тип, контракт, родителя реализации и совместимость. Установленная до родителя реализация ждёт его, после установки доступна без перезапуска. Пакеты с неподходящей версией Host API не активируются.
- [ ] Локальный `make build-windows` для новой поставки включает три отдельных подписанных `.umpkg`, ни один не содержит ключ подписи или данные аккаунтов. Документированы независимая установка, обновление и откат каждого пакета.
- [ ] Обновление одной реализации другого издателя или с ошибочной подписью отвергается с сохранением рабочей версии. При успешном обновлении и откате сохраняются совместимые привязки и профили, оба сервиса остаются независимо управляемыми.
