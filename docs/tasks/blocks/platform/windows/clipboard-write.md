# Записывать изображение и текст в буфер обмена Windows

**Статус** — 📥 К выполнению

[Этап 3 плана развития](../../../../roadmap.md#3-довести-оба-действия-до-результата-в-windows) · [ТЗ блока](../../../../blocks/platform/windows/README.md)

Дать хосту платформенные обработчики явных команд копирования из обоих плагинов. Передавать изображение через согласованный буфер SDK.

**Зависимости для старта** — [Дать модулю доступ к возможностям хоста во время invoke](../../sdk/host-capabilities.md).

**Для сквозной проверки** — [Исполнять запросы возможностей только в контексте активного вызова](../../core/capability-dispatch.md).

## Критерии приёмки

- [ ] Вставка в Paint сохраняет размер и пиксели изображения, вставка русского текста в Блокнот сохраняет символы и переводы строк.
- [ ] Занятый буфер возвращает повторяемую ошибку. Отмена до записи сохраняет прежний буфер. После неудачи ресурсы освобождаются, повторная команда может завершиться успешно.

## Проверка

На Linux проверить представление данных и обработку отказа адаптером. Пользователь на Windows пробует вставку обоих типов и повтор после освобождения буфера.
