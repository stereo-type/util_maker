## Критерии приёмки

- [ ] Ключ включает ID реализации, `connectionId` и имя секрета. Чтение, ротация и удаление одного аккаунта сохраняют данные остальных. Приложение и родительский сервис не читают секреты реализации.
- [ ] Проверка принадлежности и допустимых операций выполняется на стороне хоста. Запоздалое обновление токена после удаления аккаунта его не восстанавливает. Сбой записи сохраняет прежний рабочий токен и допускает повтор.
- [ ] В открытом профиле, DTO для UI, логах и пакетах отсутствуют пароли, authorization code и токены. Экран получает только состояние подключения.

## Проверка

Linux, тестовый SecretStore и конкурирующие операции обновления/удаления. На Windows пользователь проверяет сохранение между запусками и отзыв доступа одного из двух аккаунтов.
