# Выбирать пиксель лупой и копировать показанный цвет

**Статус** — 📥 К выполнению

[ТЗ плагина](../../../../blocks/plugins/color-picker/README.md) · [Этап «После первой поставки»](../../../../roadmap.md#после-первой-поставки)

Добавить процесс `org.utilmaker.color-picker`, действие `pick-color` и окно выбора на статическом снимке. Настройку «Формат цвета» читает плагин, регистрацию глобального сочетания выполняет хост.

**Зависимости для старта** — Можно начать с тестового кадра и буфера. Для лупы и клавиатурного управления интерфейс выборки задан в [карточке чтения пикселя](sample-pixel.md).

**Для сквозной проверки** — [Выборка цвета](sample-pixel.md) и [чтение реального кадра через SDK](../../sdk/plugin-frame-access.md).

## Критерии приёмки

- [ ] Манифест издателя `org.utilmaker` объявляет `screen.capture`, `clipboard.write`, `settings.read`. По умолчанию используется HEX. Выбор CSS RGB сохраняется после перезапуска.
- [ ] До overlay получить один снимок, скопировать в память и выполнить `frame.release`. Лупа без сглаживания показывает перекрестие и точную строку, у края экрана смещается сама лупа. В выборку попадает пиксель исходного снимка. Движение мыши не вызывает новый захват.
- [ ] Стрелки смещают выбор на один физический пиксель. Клик или Enter копирует показанную строку и закрывает окно после успеха. При занятом буфере сохраняются точка, значение и действие «Повторить копирование». Esc сохраняет прежний буфер, повторный шорткей возвращает в текущий выбор.
- [ ] Выбор доступен после истечения `expiresInMs`. При отказе захвата можно запросить новый кадр. Если геометрии недостаточно, конфигурация дисплеев изменилась или точка попала между мониторами, копирование недостоверного значения исключено. Завершение освобождает кадр и процесс.

## Проверка

В Linux проверить с тестовыми адаптерами число захватов при движении, работу стрелок, потерю геометрии, Esc и повтор записи. На Windows пользователь сверяет лупу и вставленную строку на основном и левом мониторах с разным DPI, в том числе у края.
