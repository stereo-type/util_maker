# Выбирать пиксель лупой и копировать показанный цвет

**Статус** — 👁️ На ревью

[ТЗ плагина](../../../../blocks/plugins/color-picker/README.md) · [Этап «После первой поставки»](../../../../roadmap.md#после-первой-поставки)

Добавить процесс `org.utilmaker.color-picker`, действие `pick-color` и окно выбора на статическом снимке. Настройку «Формат цвета» читает плагин, регистрацию глобального сочетания выполняет хост.

**Зависимости для старта** — Можно начать с тестового кадра и буфера. Для лупы и клавиатурного управления интерфейс выборки задан в [карточке чтения пикселя](sample-pixel.md).

**Для сквозной проверки** — [Выборка цвета](sample-pixel.md) и [чтение реального кадра через SDK](../../sdk/plugin-frame-access.md).

## Критерии приёмки

- [x] Манифест издателя `org.utilmaker` объявляет `screen.capture`, `clipboard.write`, `settings.read`. По умолчанию используется HEX. Выбор CSS RGB сохраняется после перезапуска.
- [x] До overlay получить один снимок, скопировать в память и выполнить `frame.release`. Лупа без сглаживания показывает перекрестие и точную строку, у края экрана смещается сама лупа. В выборку попадает пиксель исходного снимка. Движение мыши не вызывает новый захват.
- [x] Стрелки смещают выбор на один физический пиксель. Клик или Enter копирует показанную строку и закрывает окно после успеха. При занятом буфере сохраняются точка, значение и действие «Повторить копирование». Esc сохраняет прежний буфер, повторный шорткей возвращает в текущий выбор.
- [x] Выбор доступен после истечения `expiresInMs`. При отказе захвата можно запросить новый кадр. Если геометрии недостаточно, конфигурация дисплеев изменилась или точка попала между мониторами, копирование недостоверного значения исключено. Завершение освобождает кадр и процесс.

## Что сделано

- Добавлен `plugins/color-picker/manifest.json`: ID `org.utilmaker.color-picker`, издатель `org.utilmaker`, действие `pick-color`, возможности `screen.capture`, `clipboard.write`, `settings.read`.
- Настройка «Формат цвета» объявлена как `select` с вариантами `hex` (по умолчанию) и `rgb`; значение читается через `settings.read` и сохраняется штатным хранилищем хоста.
- Добавлен процесс `color-picker-module`: рукопожатие, чтение формата, один `frame.capture`, `frame.release` и явная машинная причина, пока SDK не передаёт байты кадра дочернему процессу.
- Добавлен `picker.rs`: `FrameData`, `FrameSource`/`FrameLease`, `Picker`, `PickerSession`, `Loupe` и `ClipboardSink`.
- Снимок копируется в память до открытия выбора, ссылка хоста освобождается сразу. `set_point` и стрелки читают только копию и не повторяют захват.
- Лупа увеличивает пиксели без сглаживания, перекрестие совпадает с выбранным пикселем, а окно сдвигается внутрь кадра у края.
- Копирование использует ровно показанную строку. Успех закрывает выбор; занятый буфер сохраняет точку и значение для повтора; Esc не трогает буфер.
- После истечения `expiresInMs` выбор продолжается по локальной копии. Смена геометрии, отсутствие геометрии и промежуток между мониторами блокируют копирование.

## Проверка

Linux, контейнер `util-maker-dev:local`:

- `cargo test -p util-maker-color-picker` — 26/26 тестов.
- `cargo test -p util-maker-core --test color_picker_module` — 3/3 теста.
- `cargo build --workspace --bins` — процесс `color-picker-module` собран.
- `cargo fmt --all -- --check` и `cargo clippy -p util-maker-color-picker --all-targets -- -D warnings` — без замечаний.

Тестами подтверждены: один захват при движении, `frame.release` до выбора, стрелки на один физический пиксель, лупа без сглаживания и у края, копирование показанной строки, занятый буфер и повтор, Esc, повторный шорткей без нового захвата, работа после `expiresInMs`, отказ захвата с повтором, смена и отсутствие геометрии, промежуток между мониторами.

## Осталось

- SDK-задача [«Дать дочернему процессу доступ к пикселям кадра»](../../sdk/plugin-frame-access.md) должна передать байты кадра. До неё процесс после `frame.release` возвращает код `2002` и причину `frame-bytes-unavailable` вместо поддельного цвета.
- На Windows пользователь проверяет реальный захват, DPI основного и левого мониторов, лупу у края и вставку в Блокнот после включения пакета в установщик в задаче [«Поставлять пипетку отдельным подписанным пакетом»](ship-package.md). Команда локальной сборки — `make build-windows`, ревизия будет указана в итоговом ответе.
