# Выбирать пиксель лупой и копировать показанный цвет

**Статус** — 👁️ На ревью

[ТЗ плагина](../../../../blocks/plugins/color-picker/README.md) · [Этап «После первой поставки»](../../../../roadmap.md#после-первой-поставки)

Добавить процесс `org.utilmaker.color-picker`, действие `pick-color` и окно выбора на статическом снимке. Настройку «Формат цвета» читает плагин, регистрацию глобального сочетания выполняет хост.

**Зависимости для старта** — Можно начать с тестового кадра и буфера. Для лупы и клавиатурного управления интерфейс выборки задан в [карточке чтения пикселя](sample-pixel.md).

**Для сквозной проверки** — [Выборка цвета](sample-pixel.md) и [чтение реального кадра через SDK](../../sdk/plugin-frame-access.md).

## Критерии приёмки

- [x] Манифест издателя `org.utilmaker` объявляет `screen.capture`, `clipboard.write`, `settings.read`. По умолчанию используется HEX. Выбор CSS RGB сохраняется после перезапуска.
- [x] До overlay получить один снимок, скопировать в память и выполнить `frame.release`. Лупа без сглаживания показывает перекрестие и точную строку, у края экрана смещается сама лупа. В выборку попадает пиксель исходного снимка. Движение мыши не вызывает новый захват.
- [x] Стрелки смещают выбор на один физический пиксель. Клик или Enter копирует показанную строку и закрывает окно после успеха. При занятом буфере сохраняются точка, значение и действие «Повторить копирование». Esc сохраняет прежний буфер, повторный шорткей возвращает в текущий выбор.
- [x] Выбор доступен после истечения `expiresInMs`. При отказе захвата можно запросить новый кадр. Если геометрии недостаточно, конфигурация дисплеев изменилась или точка попала между мониторами, копирование недостоверного значения исключено. Завершение освобождает кадр и процесс.

## Что сделано

- Добавлен `plugins/color-picker/manifest.json`: ID `org.utilmaker.color-picker`, издатель `org.utilmaker`, действие `pick-color`, возможности `screen.capture`, `clipboard.write`, `settings.read`.
- Настройка «Формат цвета» объявлена как `select` с вариантами `hex` (по умолчанию) и `rgb`; значение читается через `settings.read` и сохраняется штатным хранилищем хоста. Окно выбора читает то же значение.
- Процесс `color-picker-module` получает кадр, читает пиксели из локальной копии хоста (`pixelPath`, `FrameRef::read_pixels`), копирует их в память и сразу выполняет `frame.release`. После этого процесса кадр живёт только в памяти копии. Без `params.point` действие возвращает `awaiting-selection`; с точкой — проверяет её по геометрии мониторов, форматирует значение и пишет строку через `buffer.copy`.
- Исправлено замечание ревью: действие больше не возвращает `2002` на любом кадре. Код `2002` остался только для случая, когда хост не отдал файл пикселей или геометрию.
- Интерактивное окно выбора реализовано в хосте (`apps/desktop/ui/picker.html` и команды `get_picker_geometry`, `get_picker_frame`, `picker_set_point`, `picker_arrow`, `picker_copy`, `picker_cancel`): процесс не создаёт окон. Замороженный кадр передаётся PNG data URL, как у overlay «Скриншотов», и рисуется без сглаживания.
- Хост ведёт `PickerSession` из крейта пипетки: выборка точки, окно лупы 15 px с увеличением ×12, шаг стрелками на один физический пиксель, запрет копирования при смене геометрии дисплеев, сохранение точки при занятом буфере и повтор.
- Действие `pick-color` из трея, сочетания и кнопки в настройках открывает окно выбора; повторный вызов возвращает в уже открытое окно и не делает новый снимок.
- Кадр освобождается при успешном копировании и по Esc. Окно, закрытое без команды (Alt+F4), освобождает кадр при следующем вызове пипетки или выходе хоста.
- Лупа, перекрестие, рамка и подпись значения рисуются поверх кадра в окне выбора и не попадают в выборку: пиксель читается из исходного снимка.
- Добавлен `picker.rs`: `FrameData`, `FrameSource`/`FrameLease`, `Picker`, `PickerSession`, `Loupe` и `ClipboardSink`. Добавлены `FrameData::rgba_rows` для подложки окна и `PickerSession::frame`.
- Снимок копируется в память до открытия выбора, ссылка хоста освобождается сразу. `set_point` и стрелки читают только копию и не повторяют захват.
- Копирование использует ровно показанную строку. Успех закрывает выбор; занятый буфер сохраняет точку и значение для повтора; Esc не трогает буфер.
- После истечения `expiresInMs` выбор продолжается по локальной копии. Смена геометрии, отсутствие геометрии и промежуток между мониторами блокируют копирование.

## Проверка

Linux, контейнер `util-maker-dev:local`:

- `cargo test -p util-maker-color-picker` — 27/27 тестов.
- `cargo test -p util-maker-core --test color_picker_module` — 7/7 тестов.
- `make dev-run CMD="cargo check -p util-maker-desktop --all-targets"` — хост с окном выбора компилируется.
- `cargo fmt --all -- --check` и `cargo clippy --workspace --all-targets -- -D warnings` — без замечаний.
- `make test` — все тесты workspace.

Тестами подтверждены: чтение кадра 1024×1024 с отступом строки через реальный IPC, освобождение ссылки до выборки, ожидание точки без поддельного цвета, копирование точки в CSS RGB, отказ для точки вне мониторов и вне кадра, отсутствие геометрии и файла пикселей, некорректная координата. В переносимом крейте — один захват при движении, стрелки на один физический пиксель, лупа без сглаживания и у края, копирование показанной строки, занятый буфер и повтор, Esc, повторный вызов без нового захвата, работа после `expiresInMs`, смена и отсутствие геометрии, промежуток между мониторами, RGBA-строки без `stride`.

## Осталось

Пользователь собирает и проверяет на Windows 11 x64 (ревизия и команда — в итоговом ответе):

1. Открыть [`reference/sample.png`](../../../../plugins/color-picker/reference/sample.png) в масштабе 1:1 и выбрать точку `(40, 20)` в координатах изображения. **Ожидается:** `#2F80ED`, в Блокнот вставляется та же строка; в формате RGB — `rgb(47, 128, 237)`.
2. Вызвать действие из трея и сочетанием на основном мониторе и на мониторе слева с другим DPI. **Ожидается:** перекрестие лупы, показанный цвет и вставленная строка соответствуют одной точке; у края экрана окно лупы смещается.
3. Нажать стрелку вправо и вниз. **Ожидается:** соседние пиксели `#332211` и `#665544`.
4. Задать формат RGB, перезапустить хост, задержаться на выборе дольше `expiresInMs`, занять буфер обмена и нажать Enter, затем освободить буфер и «Повторить копирование». **Ожидается:** формат сохранился, долгий выбор работает, отказ не меняет буфер, повтор копирует выбранный цвет. Esc оставляет прежнее содержимое буфера.
5. Повторно нажать сочетание при открытом окне выбора. **Ожидается:** возврат к текущему выбору, новый снимок не создаётся.
