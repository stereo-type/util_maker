# Считывать цвет физического пикселя и форматировать HEX и RGB

**Статус** — 👁️ На ревью

[ТЗ плагина](../../../../blocks/plugins/color-picker/README.md) · [Этап «После первой поставки»](../../../../roadmap.md#после-первой-поставки)

Добавить переносимую выборку пикселя из SDR-кадра BGRA8 по физическим координатам виртуального рабочего стола.

**Зависимости для старта** — Можно брать сразу. Использовать синтетический кадр с геометрией мониторов, отрицательным началом и известными цветами.

**Для сквозной проверки** — [Интерактивная пипетка](pick-and-copy.md) использует эту выборку для лупы, предпросмотра и копирования.

## Критерии приёмки

- [x] Смещение учитывает `origin`, `stride` в байтах и порядок строк сверху вниз. Перед чтением проверяются принадлежность точки монитору, размеры и границы массива. Промежуток между мониторами и неполный кадр возвращают ошибку.
- [x] Для `ED 80 2F FF` возвращаются `#2F80ED` и `rgb(47, 128, 237)`. Альфа опускается. HEX использует шесть цифр в верхнем регистре, компоненты RGB — десятичные.
- [x] При смещении на один физический пиксель вправо или вниз берётся соответствующий сосед исходного снимка. Чёрный и белый дают `#000000` и `#FFFFFF`.

## Что сделано

- Добавлен крейт `util-maker-color-picker` с `FrameView`, `MonitorRect`, `Rgb` и `ColorFormat`.
- `FrameView::from_frame_ref` использует `FrameRef.geometry`; отсутствие геометрии возвращает `GeometryUnavailable`.
- Проверяются `origin`, `stride`, границы буфера, принадлежность монитору и кадру; промежуток между мониторами и неполный кадр отклоняются.
- Форматы `#RRGGBB` и `rgb(R, G, B)` реализованы без потери регистра и с игнорированием альфы.
- Эталон с таблицей координат: `plugins/color-picker/reference/sample.png`, `sample.json`, `README.md`.

## Проверка

- `cargo test -p util-maker-color-picker` — 14/14 тестов.
- Проверены отрицательный `origin.x`, `stride` с отступом, соседи вправо и вниз, чёрный и белый, альфа, промежуток между мониторами, точка вне кадра, неполный буфер, отсутствие геометрии и эталон JSON.
- `cargo fmt --all -- --check` и `cargo clippy --workspace --all-targets -- -D warnings` — без замечаний.
