# Считывать цвет физического пикселя и форматировать HEX и RGB

**Статус** — 📥 К выполнению

[ТЗ плагина](../../../../blocks/plugins/color-picker/README.md) · [Этап «После первой поставки»](../../../../roadmap.md#после-первой-поставки)

Добавить переносимую выборку пикселя из SDR-кадра BGRA8 по физическим координатам виртуального рабочего стола.

**Зависимости для старта** — Можно брать сразу. Использовать синтетический кадр с геометрией мониторов, отрицательным началом и известными цветами.

**Для сквозной проверки** — [Интерактивная пипетка](pick-and-copy.md) использует эту выборку для лупы, предпросмотра и копирования.

## Критерии приёмки

- [ ] Смещение учитывает `origin`, `stride` в байтах и порядок строк сверху вниз. Перед чтением проверяются принадлежность точки монитору, размеры и границы массива. Промежуток между мониторами и неполный кадр возвращают ошибку.
- [ ] Для `ED 80 2F FF` возвращаются `#2F80ED` и `rgb(47, 128, 237)`. Альфа опускается. HEX использует шесть цифр в верхнем регистре, компоненты RGB — десятичные.
- [ ] При смещении на один физический пиксель вправо или вниз берётся соответствующий сосед исходного снимка. Чёрный и белый дают `#000000` и `#FFFFFF`.

## Проверка

В Linux проверить кадр с отрицательным `origin.x`, отступом в конце строки и контрастными соседями. Сохранить эталон с таблицей координат и ожидаемых значений для последующей ручной проверки.
