# Поставлять пипетку отдельным подписанным пакетом

**Статус** — 📥 К выполнению

[ТЗ плагина](../../../../blocks/plugins/color-picker/README.md) · [Этап «После первой поставки»](../../../../roadmap.md#после-первой-поставки)

Включить `org.utilmaker.color-picker` в расширенную поставку Windows 11 x64. Пакет устанавливается и обновляется обычным менеджером Util Maker.

**Зависимости для старта** — Нужны манифест и исполняемый процесс из [карточки пипетки](pick-and-copy.md). Для экспорта использовать [формат пакета](../../../../blocks/packages/package-format.md).

**Для сквозной проверки** — [Выборка цвета](sample-pixel.md), [лупа и копирование](pick-and-copy.md) и [доступ к кадру](../../sdk/plugin-frame-access.md).

## Критерии приёмки

- [ ] Локальная сборка пользователя через `make build-windows` включает подписанный `.umpkg` с точкой входа Windows x64 и совместимым `hostApi`. Архив проходит общую проверку подписи и файлов.
- [ ] В чистом профиле доступны действие из трея и назначение сочетания. После установки следующей версии только пипетки сохраняются шорткей и формат цвета. После закрытия процесс пипетки завершается.
- [ ] На контрольном изображении 1:1 в SDR строка в Блокноте совпадает с эталоном в обоих форматах. Выбор после долгой паузы, отказ занятого буфера и повтор позволяют скопировать прежнюю точку. Esc сохраняет прежний буфер.

## Проверка

На Linux проверить упаковку подготовленных входов и подпись. Передать ревизию, команду локальной сборки, эталонное изображение с координатами и ожидаемыми значениями. Пользователь проверяет работу лупы, DPI и системного буфера на Windows.
