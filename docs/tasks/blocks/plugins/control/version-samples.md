# Подготовить две различимые версии контрольного пакета

**Статус** — ✅ Выполнена

[Этап 2 плана развития](../../../../roadmap.md#2-устанавливать-и-обновлять-инструменты-из-настроек) · [ТЗ блока](../../../../blocks/plugins/control/README.md)

На основе существующего `ping` подготовить воспроизводимые тестовые пакеты одного издателя с общими ID модуля и действия. Эти образцы нужны для воспроизведения обновления на работающем хосте.

**Зависимости для старта** — [Экспортировать подписанный пакет .umpkg](../../packages/export-package.md).

## Критерии приёмки

- [x] Одна документированная команда Makefile формирует два проверяемых архива с разными версиями, используя тестовый ключ. Образцы отделены от штатных пакетов поставки.
- [x] При вызове `ping` каждая версия сообщает собственную версию. Пересборка desktop-хоста для перехода между версиями не требуется.

## Проверка

На Linux проверить подписи обоих архивов и вызвать каждый процесс по stdio. Записать путь к образцам и ожидаемый ответ каждой версии.

Проверено: `make control-samples` создал `control-0.4.1-linux-x64.umpkg` и `control-0.5.0-linux-x64.umpkg`; `ping` каждой версии вернул собственную `moduleVersion`.
