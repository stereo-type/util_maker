# Декодировать текстовый QR из выбранного фрагмента

**Статус** — 📥 К выполнению

[ТЗ плагина](../../../../blocks/plugins/qr-code/README.md) · [Этап «После первой поставки»](../../../../roadmap.md#после-первой-поставки)

Реализовать локальное чтение QR из фрагмента изображения и различать исходы, которые окно чтения должно показать пользователю.

**Зависимости для старта** — Можно брать сразу. Использовать фиксированные изображения из стороннего генератора с известным содержимым.

**Для сквозной проверки** — [Чтение QR с экрана](read-region.md) передаст выбранные пиксели и покажет исход.

## Критерии приёмки

- [ ] Для прямого и повёрнутого на 90° QR возвращается точный текст. Поддерживаются UTF-8 с ECI, а при отсутствии ECI — ASCII и корректный UTF-8. Код вне выбранной области не участвует в поиске.
- [ ] Для отсутствующего или повреждённого QR предлагается новый выбор. При двух кодах в области возвращается требование выбрать один. Неподдерживаемая кодировка или двоичная нагрузка, непредставимая текстом, дают отдельную причину.
- [ ] Ссылки, Wi-Fi-строки, команды и разметка возвращаются как текст без открытия и исполнения. Пустой результат не инициирует копирование.

## Проверка

В Linux прогнать сторонние эталоны, включая поворот, два кода, испорченное изображение, неизвестную кодировку и двоичные данные. Зафиксировать ожидаемую строку или категорию для каждого растра.
