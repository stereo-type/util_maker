# Кодировать текст в QR без потери символов

**Статус** — 👁️ На ревью

[ТЗ плагина](../../../../blocks/plugins/qr-code/README.md) · [Этап «После первой поставки»](../../../../roadmap.md#после-первой-поставки)

Реализовать локальное преобразование текста в матрицу QR и расчёт размеров для отрисовки в физических пикселях. Результат используется действием `show-qr`.

**Зависимости для старта** — Можно брать сразу. Достаточно контрольных строк и независимого декодера.

**Для сквозной проверки** — [Окно показа QR](show-selection.md) использует матрицу и сообщает об ошибках ввода.

## Критерии приёмки

- [x] Код формата QR Code Model 2 использует коррекцию M. Unicode кодируется в UTF-8 с ECI. Ссылка с параметрами, кириллица, emoji, переносы и крайние пробелы восстанавливаются побайтно.
- [x] Пустая строка и ввод длиннее ёмкости одного QR возвращают различимые причины. Избыточный ввод не усекается.
- [x] При заданном размере окна формируется чёрно-белое изображение с целочисленным масштабом модулей и белым полем минимум в четыре модуля по каждой стороне. Если код не помещается, возвращается соответствующий результат.

## Что сделано

- Добавлен крейт `util-maker-qr-code` с `QrMatrix::encode` и `QrMatrix::render`.
- Кодирование: QR Code Model 2, коррекция M, ECI 26 (UTF-8), байтовый сегмент, версии 1–40 без усечения.
- Пустая строка возвращает `EncodeError::EmptyInput`, переполнение — `EncodeError::TooLong`.
- Отрисовка: целый масштаб, центрирование, белое поле не меньше четырёх модулей; нулевое окно и слишком маленькая область дают отдельные ошибки.
- Описание контракта и контрольных строк: `plugins/qr-code/README.md`.

## Проверка

Linux, контейнер `util-maker-dev:local`:

- `cargo test -p util-maker-qr-code` — 7/7 тестов.
- Отрисованный растр независимо декодирован библиотекой `rqrr 0.11`: URL с параметрами и строка `  Привет, мир! 👋\nСтрока 2\t— конец  ` совпали побайтно.
- Проверены пустой ввод, 5000 байт, слишком маленькое окно, целый масштаб, поле в четыре модуля и только чёрно-белые пиксели.
- `cargo fmt --all -- --check` и `cargo clippy --workspace --all-targets -- -D warnings` — без замечаний.
