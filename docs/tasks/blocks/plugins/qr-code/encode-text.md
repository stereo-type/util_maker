# Кодировать текст в QR без потери символов

**Статус** — 📥 К выполнению

[ТЗ плагина](../../../../blocks/plugins/qr-code/README.md) · [Этап «После первой поставки»](../../../../roadmap.md#после-первой-поставки)

Реализовать локальное преобразование текста в матрицу QR и расчёт размеров для отрисовки в физических пикселях. Результат используется действием `show-qr`.

**Зависимости для старта** — Можно брать сразу. Достаточно контрольных строк и независимого декодера.

**Для сквозной проверки** — [Окно показа QR](show-selection.md) использует матрицу и сообщает об ошибках ввода.

## Критерии приёмки

- [ ] Код формата QR Code Model 2 использует коррекцию M. Unicode кодируется в UTF-8 с ECI. Ссылка с параметрами, кириллица, emoji, переносы и крайние пробелы восстанавливаются побайтно.
- [ ] Пустая строка и ввод длиннее ёмкости одного QR возвращают различимые причины. Избыточный ввод не усекается.
- [ ] При заданном размере окна формируется чёрно-белое изображение с целочисленным масштабом модулей и белым полем минимум в четыре модуля по каждой стороне. Если код не помещается, возвращается соответствующий результат.

## Проверка

В Linux декодировать отрисованный растр независимым декодером. Сравнить строки целиком, проверить пустой ввод, переполнение и слишком малую область вывода.
