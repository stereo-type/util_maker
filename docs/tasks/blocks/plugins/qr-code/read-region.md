# Читать QR с экрана и копировать из предпросмотра

**Статус** — 👁️ На ревью

[ТЗ плагина](../../../../blocks/plugins/qr-code/README.md) · [Этап «После первой поставки»](../../../../roadmap.md#после-первой-поставки)

Реализовать handler `read-qr-region` для пакета QR. После выбора области пользователь видит содержимое и решает, копировать ли его.

**Зависимости для старта** — Можно начать на тестовом кадре, с подставным декодером и буфером. Идентификаторы пакета и действий определены в ТЗ.

**Для сквозной проверки** — [Декодер](decode-region.md), [процесс с манифестом](show-selection.md) и [доступ к кадру](../../sdk/plugin-frame-access.md).

## Критерии приёмки

- [x] До появления рамки снять экран через `screen.capture`, прочитать пиксели и освободить `FrameRef`. Выбор на другом мониторе учитывает его DPI. В декодер передаётся только содержимое выделения. Хост хранит снимок до выбора, а процесс получает его через `frame.capture` и освобождает `frame.release`; в декодер идёт вырезанная область.
- [x] Один QR открывается как обычный текст, включая URL, команды и разметку. Для отсутствующего, повреждённого или нескольких кодов доступен новый выбор. Неподдерживаемые данные показывают причину. Копирование доступно только для непустого текстового результата. Исходы `no-code`, `damaged` и `multiple` возвращают причину и кнопку «Выбрать другую область».
- [x] Только кнопка «Копировать» пишет показанную строку через `clipboard.write`. Занятый буфер оставляет предпросмотр для повтора. Esc отменяет выбор, декодирование или предпросмотр, включая поздний ответ. Повторная команда активирует текущую сессию. Копирование выполняет хост по кнопке общего окна результата; показ и декодирование его не меняют, повтор команды возвращает к открытому предпросмотру.
- [x] После закрытия снимок и содержимое освобождаются. В журнале остаются только технические сведения о вызове.


## Что сделано

- `plugins/qr-code/src/main.rs`: handler `read-qr-region` принимает `params.selection`, запрашивает `frame.capture` только для выбранного прямоугольника, читает пиксели, освобождает `frame.release` и декодирует область через `decode_qr`. Текстовый исход возвращает строку и версию; остальные — машинную причину и признак нового выбора.
- `crates/platform/src/lib.rs`: `FrozenFrame` и `NativeHost::with_frozen_frame`. Хост отдаёт `frame.capture` из заранее снятого кадра, вырезает запрошенную область во временный файл, удаляет его по `frame.release` или при завершении вызова.
- `apps/desktop/src/main.rs`: окно выбора получило режим QR; `qr_read_region` проверяет область, освобождает снимок и вызывает действие с готовым кадром. `retry_qr_read` открывает выбор заново; успешный предпросмотр активируется повторной командой; закрытие окна очищает текст.
- `apps/desktop/ui/overlay.html`: режим `?mode=qr` отправляет область в `qr_read_region`, а не в редактор снимка.
- `apps/desktop/ui/result.html`: кнопка «Выбрать другую область» для ошибок чтения и обычная кнопка «Копировать» для успешного текста.
- После проверки на Windows исправлено зависание: `qr_read_region` больше не закрывает окно выбора изнутри обработчика и запускает чтение в отдельном потоке. Окно закрывается отложенно, уже после ответа команды, а результат показывается, когда плагин закончил.
- В [ТЗ плагина](../../../../blocks/plugins/qr-code/README.md) уточнять не пришлось: поведение соответствует разделу «Прочитать QR с экрана».

## Проверка

Linux, контейнер `util-maker-dev:local`:

- `cargo test -p util-maker-qr-code` — 13 unit-тестов и 5 тестов эталонов; все прошли.
- `cargo test -p util-maker-core --test qr_code_module` — 7 тестов IPC-границы, включая чтение из кадра, `no-code` для пустой области и обязательный `frame.release`.
- `cargo test -p util-maker-platform --lib frozen` — снимок отдаётся `frame.capture` с обрезкой по области, файл удаляется после release.
- `cargo clippy -p util-maker-platform -p util-maker-qr-code -p util-maker-desktop --all-targets -- -D warnings` — без замечаний; `rustfmt --check` по изменённым файлам чист.
- `node --check` для встроенных скриптов `overlay.html` и `result.html` — синтаксис без ошибок.
- `make check` — версия, rustfmt, Clippy, сборка workspace и все тесты прошли (EXIT=0).

Windows: `make build-windows`, установить сборку. Выделить QR на втором мониторе без сети, убедиться, что видно видео/кадр и область совпадает с итогом; закрыть предпросмотр с Esc, повторить и нажать «Копировать». Проверить занятый буфер: окно с текстом остаётся, после освобождения буфера копирование повторяется. Отдельно проверить пустую область, повреждённый код и два кода рядом — должна быть кнопка «Выбрать другую область».
