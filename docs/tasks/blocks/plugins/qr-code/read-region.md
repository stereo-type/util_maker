# Читать QR с экрана и копировать из предпросмотра

**Статус** — 📥 К выполнению

[ТЗ плагина](../../../../blocks/plugins/qr-code/README.md) · [Этап «После первой поставки»](../../../../roadmap.md#после-первой-поставки)

Реализовать handler `read-qr-region` для пакета QR. После выбора области пользователь видит содержимое и решает, копировать ли его.

**Зависимости для старта** — Можно начать на тестовом кадре, с подставным декодером и буфером. Идентификаторы пакета и действий определены в ТЗ.

**Для сквозной проверки** — [Декодер](decode-region.md), [процесс с манифестом](show-selection.md) и [доступ к кадру](../../sdk/plugin-frame-access.md).

## Критерии приёмки

- [ ] До появления рамки снять экран через `screen.capture`, прочитать пиксели и освободить `FrameRef`. Выбор на другом мониторе учитывает его DPI. В декодер передаётся только содержимое выделения.
- [ ] Один QR открывается как обычный текст, включая URL, команды и разметку. Для отсутствующего, повреждённого или нескольких кодов доступен новый выбор. Неподдерживаемые данные показывают причину. Копирование доступно только для непустого текстового результата.
- [ ] Только кнопка «Копировать» пишет показанную строку через `clipboard.write`. Занятый буфер оставляет предпросмотр для повтора. Esc отменяет выбор, декодирование или предпросмотр, включая поздний ответ. Повторная команда активирует текущую сессию.
- [ ] После закрытия снимок и содержимое освобождаются. В журнале остаются только технические сведения о вызове.

## Проверка

В Linux проверить отмену отложенного декодирования, несколько кодов, ошибку записи и повтор. На Windows пользователь выделяет QR на втором мониторе без сети, закрывает предпросмотр с Esc, повторяет и вставляет точную строку в Блокнот.
