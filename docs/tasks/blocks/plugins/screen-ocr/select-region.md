# Запускать OCR из трея и выбирать область на снимке экрана

**Статус** — 👁️ На ревью

[ТЗ плагина](../../../../blocks/plugins/screen-ocr/README.md) · [Этап «После первой поставки»](../../../../roadmap.md#после-первой-поставки)

Добавить манифест и исполняемую точку входа `org.utilmaker.screen-ocr / recognize-region`. Действие читает языки через SDK и показывает выбор области на одном зафиксированном снимке.

**Зависимости для старта** — Можно брать сразу. Для разработки доступны контракт кадра и тестовый источник пикселей. Для обработчика выбора достаточно подставного распознавателя.

**Для сквозной проверки** — [Доступ дочернего процесса к кадру](../../sdk/plugin-frame-access.md), [распознавание](recognize-crop.md) и [окно результата](edit-result.md).

## Критерии приёмки

- [x] Манифест издателя `org.utilmaker` объявляет `screen.capture`, `settings.read`, `clipboard.write` и поле «Языки распознавания». Значение по умолчанию — «Русский и английский». После смены на один язык следующий вызов получает сохранённое значение.
- [x] Шорткей и трей вызывают одно действие `recognize-region`. Процесс читает языки, захватывает экран, копирует пиксели через `FrameRef::read_pixels` и освобождает ссылку через `frame.release` до открытия выбора. Сбой чтения пикселей или истечение ссылки возвращают машинную причину и позволяют запросить новый снимок.
- [x] Выделение нормализуется в любом направлении и передаёт физические координаты с учётом геометрии каждого монитора. Вырожденный прямоугольник оставляет выбор открытым. При повторном вызове активируется текущая сессия без нового захвата.
- [x] Esc закрывает выбор и освобождает владеющую копию кадра. Ожидание дольше `expiresInMs` не мешает выбору: он идёт по сохранённым пикселям.

## Что сделано

- Добавлен `plugins/screen-ocr/manifest.json`: ID `org.utilmaker.screen-ocr`, издатель `org.utilmaker`, действие `recognize-region`, возможности `screen.capture`, `settings.read`, `clipboard.write`, настройка «Языки распознавания» (`rus+eng`, `rus`, `eng`).
- Добавлен процесс `screen-ocr-module`: рукопожатие, чтение языка через `settings.read`, один `frame.capture`, чтение локального файла пикселей через `FrameRef::read_pixels`, обязательный `frame.release` и явные машинные причины отказа.
- Добавлен `region.rs`: `RegionFrame` с геометрией мониторов, `RegionSession` с нормализацией любого направления, `RegionPicker` с повторным вызовом, выбором по сохранённой копии и отменой.
- Процесс принимает необязательные `params` для будущего overlay: `anchor`/`cursor`, `selection` и `cancel`. Без них возвращается `awaiting-selection`.
- Обновлены конструкторы `FrameRef` у существующих тестов и плагина «Пипетка цвета» после появления необязательного `pixelPath` в SDK.

## Проверка

Linux, контейнер `util-maker-dev:local`:

- `cargo test -p util-maker-screen-ocr` — 19 unit-тестов и 2 интеграционных теста с реальным Tesseract 5.3.0 / моделями `rus`, `eng`.
- `cargo test -p util-maker-core --test screen_ocr_module` — 5/5 тестов IPC-границы.
- Проверено порядок `settings.read` → `frame.capture` → `frame.release`, отсутствие повторного захвата при выборе и повторном вызове, обратное выделение через два монитора, вырожденный прямоугольник, Esc и выбор после истечения `expiresInMs`.
- `cargo build --workspace --bins`, `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets -- -D warnings` и `cargo test --workspace --all-targets` — без замечаний.
- `make check-version` — версия `0.4.24` согласована с новым манифестом.
