# Панель редактора скриншота: фигуры, стрелки и копирование

**Статус** — ✅ Выполнена

**Основание** — [Редактор области](region-editor.md) · [Выбор области](selection-crosshair.md)

## Наблюдение

В текущем overlay нет привычной панели инструментов. Нужен упрощённый редактор
как в инструменте выделения Яндекса: после выделения области можно добавить
стрелку или фигуру и скопировать результат.

## Ожидаемое поведение

После выделения рядом с областью появляется компактная панель:

- стрелка;
- прямоугольник;
- эллипс;
- отмена последней фигуры;
- копировать;
- закрыть/отмена.

Сохранение файла пока не нужно. Аннотации рисуются поверх выбранной области;
панель, курсор и маркеры в результат не попадают. Enter копирует, Esc
закрывает без изменения буфера.

## Критерии приёмки

- [ ] Панель содержит стрелку, прямоугольник, эллипс, отмену, копирование и
  закрытие.
- [ ] Фигуры рисуются в координатах выбранной области и остаются после
  перерисовки.
- [ ] «Отменить» удаляет только последнюю фигуру.
- [ ] Копирование кладёт в буфер только выделение с фигурами, без панели и
  курсора.
- [ ] Enter копирует; Esc закрывает без записи.
- [ ] Занятый буфер оставляет выделение и фигуры для повтора.
- [ ] Сохранение файла отсутствует.
- [ ] Панель читается в светлой и тёмной теме, доступна с клавиатуры.

## Проверка

Windows: выделить область, добавить стрелку, прямоугольник и эллипс, отменить
одну фигуру, скопировать в Paint; проверить занятый буфер и Esc.

0.4.18: отдельное окно редактора со стрелкой, рамкой, эллипсом, отменой и копированием; сохранения нет.
