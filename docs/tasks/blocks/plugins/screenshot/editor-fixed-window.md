# Фиксировать размер окна редактора независимо от выделения

**Статус** — 📥 К выполнению

**Основание** — [Редактор области](region-editor.md) · [Референс редактора](annotation-toolbar.md)

## Наблюдение

Сейчас окно редактора создаётся под размер выделения:
`width.max(360) × height + 74`. Из-за этого при каждом новом выделении окно
прыгает по размеру и положению, а маленькая область даёт неудобное окно.

## Ожидаемое поведение

- Внешний размер окна редактора постоянный и не зависит от области.
- Окно открывается в предсказуемом месте, при необходимости центрируется.
- Выделение отображается внутри рабочей области целиком, без растяжения и
  обрезки; вокруг допустимы нейтральные поля.
- Панель инструментов и нижняя панель всегда видны и не перекрывают снимок.
- На 100/150/200 % окно остаётся читаемым, кнопки не обрезаются.

## Критерии приёмки

- [ ] Окно имеет одинаковый внешний размер для области 50×50 и 1200×800.
- [ ] Изображение вписывается целиком, сохраняет пропорции.
- [ ] Панели не перекрывают изображение.
- [ ] Положение окна не зависит от координат выделения.
- [ ] Размер проверен на 100/150/200 %.

## Проверка

Windows: выделить маленькую и большую область, сравнить внешние размеры окна,
убедиться, что снимок целиком виден и панели доступны.
