# Сделать интерфейс редактора как в референсе Яндекса

**Статус** — 📥 К выполнению

**Основание** — [Панель редактора](annotation-toolbar.md) · [Фиксированное окно](editor-fixed-window.md)

## Наблюдение

Сейчас инструменты — текстовые кнопки в нижней панели, цвет фиксированный,
копирование и закрытие находятся там же. Нужен компактный редактор как в
инструменте выделения Яндекса.

## Ожидаемое поведение

**Верхняя панель (app bar):**

- иконки инструментов: стрелка, прямоугольник, эллипс, линия/карандаш;
- отмена последней фигуры и очистка;
- выбор цвета инструмента (палитра или несколько свотчей);
- активный инструмент и цвет визуально выделены;
- у каждой иконки есть доступное имя и подсказка.

**Нижняя панель справа:**

- «Копировать»;
- «Сохранить»;
- «Закрыть».

Сохранение сохраняет результат в файл; копирование кладёт в буфер только
снимок с фигурами, без панелей. Обе кнопки доступны с клавиатуры, состояния
и ошибки показываются текстом.

## Критерии приёмки

- [ ] Инструменты — иконки в верхней панели, текстовые подписи убраны.
- [ ] Есть выбор цвета, он применяется к новым фигурам.
- [ ] Активный инструмент и цвет видны.
- [ ] «Копировать», «Сохранить», «Закрыть» — в нижней панели справа.
- [ ] Копирование не включает панели и курсор.
- [ ] Сохранение создаёт файл с выбранным расширением/путём.
- [ ] Undo/очистка работают; горячие клавиши задокументированы.
- [ ] Интерфейс читается в тёмной/светлой теме и на 150/200 %.

## Проверка

Windows: выделить область, нарисовать стрелку/рамку/эллипс разными цветами,
отменить, скопировать в Paint, сохранить файл, закрыть.
