# Добавить исполняемый процесс плагина «Скриншоты»

**Статус** — ✅ Выполнена

[Этап 1 плана развития](../../../../roadmap.md#1-подготовить-два-исполняемых-плагина-и-экспорт-пакетов)

**Основание** — [ТЗ плагина](../../../../blocks/plugins/screenshot/README.md) и [контракт SDK](../../../../blocks/sdk/README.md).

В каталоге плагина уже есть библиотека сведения изображения. Добавить манифест и исполняемую точку входа, чтобы существующий хост мог согласовать API и вызвать действие `org.utilmaker.screenshot / capture-region` через stdio. Эта карточка закрывает границу процесса. Захват реального рабочего стола, overlay и запись в буфер проверяются при подключении Windows-адаптера.

**Зависимости для старта** — существующие SDK и библиотека плагина. Работу можно вести отдельно от экспортёра пакетов и переводчика.

## Критерии приёмки

- [x] Манифест проходит существующую проверку SDK. Идентификаторы модуля и действия совпадают с объявленными в общем ТЗ. Точки входа соответствуют именам собираемых файлов.
- [x] На Linux проверка запускает отдельный процесс, выполняет `initialize`, передаёт `invoke` для `capture-region` и получает ответ с тем же идентификатором запроса. При отсутствии источника кадра обработчик сообщает ошибку. Успешное копирование в этом случае не показывается.
- [x] Неизвестное действие возвращает `ACTION_NOT_FOUND`. После `shutdown` процесс завершается. В README плагина описано, как воспроизвести проверку через Makefile.

## Что сделано

- Добавлены `plugins/screenshot/manifest.json` и процесс `screenshot-plugin` на SDK `run_stdio`.
- Действие `capture-region` при отсутствии источника кадра возвращает код `2001` и причину `capture_unavailable`; успешное копирование не имитируется.
- Неизвестное действие возвращает `ACTION_NOT_FOUND`; после `shutdown` процесс завершается.
- README плагина описывает состав, точку входа и команду проверки.

## Проверка

Linux, контейнер `util-maker-dev:local`:

- `make screenshot-check` — 2 теста процесса: манифест и действие; отсутствие кадра; неизвестное действие.
- `make lint` — Clippy без замечаний.
- Windows-проверка границы процесса не требуется; реальный захват и overlay проверяются в следующих задачах.

Закрыта по Linux-проверкам: граница процесса и манифест подтверждены тестами, ручная проверка Windows для этой карточки не требуется.
