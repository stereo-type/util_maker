# Добавить исполняемый процесс плагина «Скриншоты»

**Статус** — 📥 К выполнению

**Основание** — [ТЗ плагина](../../../../blocks/plugins/screenshot/README.md) и [контракт SDK](../../../../blocks/sdk/README.md).

В каталоге плагина уже есть библиотека сведения изображения. Добавить манифест и исполняемую точку входа, чтобы существующий хост мог согласовать API и вызвать действие `org.utilmaker.screenshot / capture-region` через stdio. Эта карточка закрывает границу процесса. Захват реального рабочего стола, overlay и запись в буфер проверяются при подключении Windows-адаптера.

**Зависимости для старта** — существующие SDK и библиотека плагина. Работу можно вести отдельно от экспортёра пакетов и переводчика.

## Критерии приёмки

- [ ] Манифест проходит существующую проверку SDK. Идентификаторы модуля и действия совпадают с объявленными в общем ТЗ. Точки входа соответствуют именам собираемых файлов.
- [ ] На Linux проверка запускает отдельный процесс, выполняет `initialize`, передаёт `invoke` для `capture-region` и получает ответ с тем же идентификатором запроса. При отсутствии источника кадра обработчик сообщает ошибку. Успешное копирование в этом случае не показывается.
- [ ] Неизвестное действие возвращает `ACTION_NOT_FOUND`. После `shutdown` процесс завершается. В README плагина описано, как воспроизвести проверку через Makefile.

## Проверка

Заполняется при передаче на ревью.
