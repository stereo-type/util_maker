## Критерии приёмки

- [ ] Старый профиль с `saveDirectory` по умолчанию пишет в прежнюю папку. Захват, правка, шорткей и копирование доступны без сети и без установленных провайдеров.
- [ ] Кнопка «Сохранить» передаёт сведённый PNG с аннотациями в выбранную папку указанного аккаунта. Удалённые вызовы идут из проверенного контекста сохранения редактора. Другим приложениям доступен тот же SDK-маршрут.
- [ ] UI показывает назначение и подтверждение либо причину отказа. При ошибке сохраняет кадр и правки, позволяет повторить тот же запрос или явно сохранить локально. Двойной клик и поздний ответ не создают ложный успех либо второй запрос в новое назначение.

## Проверка

Linux, тестовый writer и fake provider, контрольный PNG и сверка байтов. Windows, оба реальных сервиса, отмена, занятая сеть и повтор на том же снимке.
