# Выбирать область и редактировать снимок поверх рабочего стола

**Статус** — ✅ Выполнена

[Этап 3 плана развития](../../../../roadmap.md#3-довести-оба-действия-до-результата-в-windows) · [ТЗ блока](../../../../blocks/plugins/screenshot/README.md)

Подключить интерактивный редактор к `capture-region` и существующему `render`. Начать на тестовом источнике кадра и подменном буфере. Модуль владеет выбором, аннотациями и решением о копировании.

## Критерии приёмки

- [x] Overlay открывается после получения кадра. Перетаскивание задаёт область, стрелка, рамка и отмена последней правки дают ожидаемые пиксели. Панель не входит в результат.
- [x] Enter копирует также область без аннотаций. Занятый буфер оставляет кадр для повтора. Esc сохраняет прежний буфер и закрывает редактор.
- [x] Повторный шорткей возвращает к текущему захвату. Завершение освобождает кадр и окно. Работает выделение на стыке мониторов с разным DPI.

## Что сделано

- `EditorSession` принимает кадр, выбор, аннотации и отмену; повторный вызов возвращает текущий захват.
- `ClipboardSink` и `CopyOutcome` отделяют успешное копирование от занятого буфера: при занятости кадр и правки сохраняются.
- `escape` освобождает кадр, не трогая прежний буфер; успешное копирование освобождает кадр и аннотации.
- Сведение результата использует существующий `render`; панель и маркеры в изображение не входят.

## Проверка

Linux, контейнер `util-maker-dev:local`:

- `cargo test -p util-maker-screenshots` — 11 тестов: сведение, отмена последней правки, копирование без аннотаций, занятый буфер, Esc, повторный захват и выбор через начало координат.
- `make screenshot-check` — тесты плагина и процесса.
- `make lint` — Clippy без замечаний.

На Windows-адаптере остаётся реальное overlay-окно, захват мониторов, системный буфер и проверка в Paint; эти шаги входят в задачи платформы.

## Реализовано в хосте

- Полноэкранный overlay на виртуальном рабочем столе: снимок до показа окна.
- Выделение мышью, стрелка, рамка, отмена последней правки.
- Enter и кнопка «Копировать» пишут только выбранную область; панель и маркеры не попадают.
- Esc закрывает редактор без записи в буфер.
- Копирование идёт в системный буфер Windows (CF_DIB).

Host 0.4.18: прозрачное окно выбора, без затемнения; после выделения открывается отдельное окно редактора, Esc закрывает без зависания.
