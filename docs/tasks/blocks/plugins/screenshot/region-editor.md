# Выбирать область и редактировать снимок поверх рабочего стола

**Статус** — 📥 К выполнению

Подключить интерактивный редактор к `capture-region` и существующему `render`. Начать на тестовом источнике кадра и подменном буфере. Модуль владеет выбором, аннотациями и решением о копировании.

## Критерии приёмки

- [ ] Overlay открывается после получения кадра. Перетаскивание задаёт область, стрелка, рамка и отмена последней правки дают ожидаемые пиксели. Панель не входит в результат.
- [ ] Enter копирует также область без аннотаций. Занятый буфер оставляет кадр для повтора. Esc сохраняет прежний буфер и закрывает редактор.
- [ ] Повторный шорткей возвращает к текущему захвату. Завершение освобождает кадр и окно. Работает выделение на стыке мониторов с разным DPI.

## Проверка

На Linux проверить состояние редактора и результат на эталонном кадре. На Windows пользователь вставляет контрольную область в Paint, повторяет с двумя DPI и при занятом буфере.
