# Не показывать заблокированный перевод как успех

**Статус** — ✅ Выполнена

**Основание** — [Связать выделение и окно результата](translate-selection.md)

## Наблюдение

При вызове перевода по сочетанию окно результата показывает статус **«Успех»**
и зелёный статус, хотя текст:

```text
Исходное окно потеряло контекст: выделение недоступно, запрос не отправлен.
```

Перевод не выполнен, HTTP-запроса не было, но пользователь видит успешный
результат.

## Ожидаемое поведение

- Заблокированный/пустой источник показывается как предупреждение или ошибка,
  а не «Успех».
- Кнопка «Копировать» не показывается для сообщения об ошибке.
- Пользователь понимает, что нужно выделить текст и повторить.

## Критерии приёмки

- [ ] Для `blocked`/`context-lost`/`password` статус окна — предупреждение или
  ошибка.
- [ ] «Копировать» скрыта.
- [ ] Сообщение содержит причину и следующий шаг.
- [ ] Успешный перевод по-прежнему показывается как «Успех».

## Проверка

Windows: вызвать перевод без выделения/с потерей контекста, затем с реальным
выделением и ключом.

0.4.6: при потере контекста окно показывает «Требует действия», кнопка копирования скрыта.
