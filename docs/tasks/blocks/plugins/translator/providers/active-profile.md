## Критерии приёмки

- [ ] Профили Яндекса и Google раздельно сохраняют языки и ссылки на ключи. Автоопределение доступно для исходного языка, целевой по умолчанию — русский. Следующий вызов использует выбранный профиль и только его ключ.
- [ ] Проверка отправляет фиксированную фразу существующим адаптером. Перевод отправляет только переданный текст. При отсутствии ключа, отмене или ошибке запрос не переключается на другой сервис.
- [ ] Таймаут 10 с и причины отказа доступны вызывающей стороне. В файлах настроек и диагностике отсутствуют секреты и текст перевода.

## Проверка

На Linux через `make test` проверить переключение, повторное открытие профилей, отмену и ошибки на подменном транспорте. Реальные ключи обоих сервисов использует пользователь при проверке Windows.

0.4.30: команда формы `testConnection` подключена через `command_with_host`.
Без сохранённого ключа возвращает `missing-profile` и не делает HTTP-запрос.
