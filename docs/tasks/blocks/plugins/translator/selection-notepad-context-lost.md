# Читать выделение Блокнота через UI Automation

**Статус** — 📥 К выполнению

**Основание** — [Связать выделение и окно результата](translate-selection.md) · [UI Automation](../../platform/windows/selection-source.md)

## Наблюдение

На Windows 0.4.5 в Блокноте выделен весь текст (`Ctrl+A`), затем нажато
`Ctrl+Shift+T`. Окно результата сообщило:

```text
Исходное окно потеряло контекст: выделение недоступно, запрос не отправлен.
```

Нужно проверить, теряется ли фокус до чтения UI Automation или адаптер не
получает TextPattern у Блокнота. В текущей проверке автоматизация фокуса могла
повлиять на результат, поэтому воспроизвести вручную.

## Ожидаемое поведение

- Выделенный текст Блокнота читается и уходит в перевод.
- Если TextPattern недоступен, показывается «не поддержано» и ручной ввод, а не
  ложная потеря контекста.
- Парольное поле и пустое выделение по-прежнему не отправляют запрос.

## Критерии приёмки

- [ ] Ручное выделение в Блокноте и вызов сочетанием дают текст в запросе.
- [ ] Повторный вызов после смены фокуса не теряет источник.
- [ ] В журнале видно, какой шаг UI Automation отказал.

## Проверка

Windows: Блокнот и Edge, оба порядка выделения; проверить пустое выделение и
парольное поле.
