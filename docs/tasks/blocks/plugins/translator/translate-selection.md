## Критерии приёмки

- [ ] Выделенный текст уходит один раз и без окружающего документа. При пустом диапазоне подсказка сохраняет фокус, после одного жеста запускается перевод. При неподдерживаемом выделении доступен явный ручной ввод. Отмена ожидания и парольное поле дают ноль запросов.
- [ ] При запросе показан прогресс, затем перевод рядом с выделением либо на мониторе источника. Только явное копирование меняет буфер. При отсутствии ключа открывается нужный профиль.
- [ ] Esc закрывает окно, новый вызов исключает поздний ответ предыдущего. Видны ошибки выбранного провайдера и повтор по команде пользователя.

## Проверка

На Linux проверить полный маршрут с тестовыми адаптерами и задержанным ответом. Пользователь на Windows проверяет оба порядка выделения, ручной ввод, настройку ключа и копирование в Блокноте и Edge.
