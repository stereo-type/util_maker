## Критерии приёмки

- [ ] `putFile` проверяет относительные сегменты папки, имя файла, MIME, размер и неизменную ссылку. Некорректный путь, выход из корня и превышение лимита отвергаются до сетевого вызова.
- [ ] Сервис отправляет запись выбранному в контексте аккаунту, возвращает объект и назначение только после подтверждения. Публичный API приложения не раскрывает токены, URL загрузки и детали транспорта.
- [ ] Одинаковый `requestId` и содержимое обозначают одну запись в фиксированное назначение. Смена данных с тем же ID отклоняется. Конфликт, отказ доступа и неопределённый результат проходят до UI раздельно. Сервис работает с тестовым вкладом без ветвления по ID платформ.

## Проверка

Linux, контрактный набор с тестовым вкладом и двумя потребителями. Передать этот же набор авторам обеих реализаций, включая повтор после потери ответа.
