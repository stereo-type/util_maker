## Критерии приёмки

- [ ] Вход открывается системным браузером, использует PKCE S256, `state`, одноразовый callback на loopback и `drive.file`. Отмена, неверный `state`, повтор callback и таймаут сохраняют предыдущую конфигурацию и закрывают listener.
- [ ] Два входа привязаны к соответствующим `connectionId`. При повторной авторизации обнаруживается подмена аккаунта. Refresh изолирован, успешный ответ без нового refresh token сохраняет предыдущий. Отзыв одного аккаунта требует повторного входа только для него.
- [ ] В инструкции указано, как включить API, получить desktop client, настроить consent и тестовых пользователей. Штатная поставка использует настроенный клиент. Пользовательские секреты отсутствуют в исходниках, артефактах и диагностике.

## Проверка

Linux, локальный OAuth-сервер, перестановка callback и повторный вход. На Windows пользователь подтверждает вход в два реальных аккаунта тестового проекта и отзыв токена одного из них.
