## Критерии приёмки

- [ ] В `drive.file` можно выбрать созданную приложением папку, а для имеющейся папки явно предоставить доступ. В параметрах сохраняется folder ID. Переименование и одноимённые папки не перенаправляют запись.
- [ ] Файл загружается с заданными `parents`, MIME и байтами. Для больших PNG действует возобновляемая загрузка. Обрыв, повтор и перезапуск процесса сверяются по ранее выделенному ID объекта без дубликата.
- [ ] При 401 после допустимого обновления токена, 403, квоте, rate limit и отсутствии сети возвращается соответствующая причина. Публичная ссылка и новые разрешения на файл при сохранении не создаются.

## Проверка

Linux, поддельный Drive API, два parent ID с одним именем, потеря последнего ответа и сверка файла. На Windows пользователь открывает контрольный PNG в выбранном «Моём диске».
