## Критерии приёмки

- [ ] Для двух серверов либо аккаунтов независимо сохраняются имя подключения, HTTPS URL, пользователь и ссылка на пароль приложения. Проверка доступа учитывает установку в подкаталоге. Учётные данные не отправляются на другой origin.
- [ ] `PROPFIND`, создание папки и условная загрузка поддерживают кириллицу и пробелы, параллельное создание папки и коллизию имени. Чужой файл не перезаписывается.
- [ ] Таймаут после принятого сервером запроса проверяется в том же назначении. Успешный повтор даёт один файл. Отзыв пароля, отсутствие прав, квота, сетевой отказ и неопределённое состояние различимы.

## Проверка

Linux, HTTP-фикстуры с анализом запросов и сравнение байтов. На Windows пользователь подключает свой тестовый сервер и открывает PNG в Nextcloud.
