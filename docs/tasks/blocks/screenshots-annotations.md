# Нанести стрелку и рамку на выделенную область

**Статус** — К выполнению

**Основание** — [ТЗ блока «Скриншоты»](../../blocks/screenshots.md).

Реализовать формирование итогового изображения по кадру, прямоугольнику в физических пикселях и списку аннотаций. Для проверки использовать контрольный кадр в памяти.

## Критерии приёмки

- [ ] Размер результата совпадает с размером выбранного прямоугольника, включая область с отрицательными координатами рабочего стола.
- [ ] После добавления стрелки и рамки отмена последней правки оставляет только стрелку.
- [ ] При копировании без аннотаций результат совпадает с исходной областью пиксель в пиксель. Панель и маркеры в результат не входят.
