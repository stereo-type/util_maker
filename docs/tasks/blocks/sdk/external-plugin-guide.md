# Передать пример подключения стороннего плагина с двумя действиями

**Статус** — 👁️ На ревью

[Этап 4 плана развития](../../../roadmap.md#4-принять-первую-поставку-windows) · [ТЗ блока](../../../blocks/sdk/README.md)

Подготовить переносимый пример с новым ID и двумя различимыми действиями. Описать сборку, подпись, доверие издателю, установку и выпуск следующей версии. Оставить прототип `control/ping` рабочим.

**Зависимости для старта** — [Экспортировать подписанный пакет .umpkg](../packages/export-package.md), [Описать пользовательские настройки и команды формы в манифесте](module-settings.md).

**Для сквозной проверки** — [Подключить редактор и глобальные клавиши к общему реестру](../desktop/live-shortcuts.md), [Управлять локальными пакетами из настроек](../desktop/package-management.md), [Атомарно переключать версию пакета и откатывать настройки](../packages/update-rollback.md).

## Критерии приёмки

- [x] Следуя инструкции с чистого checkout, разработчик получает подписанный пакет нового ID. Оба действия вызываются через действующий SDK.
- [ ] На том же хосте пользователь добавляет открытый ключ, устанавливает пакет, назначает разные сочетания и обновляет пакет. Сохранившийся ID действия сохраняет привязку.

## Проверка

На Linux, контейнер `util-maker-dev:local`:

- `make example-package` — собран и проверен `echo-plugin-0.1.0-linux-x64.umpkg` (`com.example.echo`, `fileCount=1`, `entrypoint=echo-plugin`).
- `actions.jsonl` — `hello` и `clock` вернули `status: ok` через `run_stdio`; затем процесс ответил на `shutdown`.
- `make example-package EXAMPLE_VERSION=0.2.0` — тот же ID и тот же ключ `com.example`, версия в манифесте и `hello.moduleVersion` стала `0.2.0`; ID действий `hello`/`clock` сохранились.
- Архив `0.1.0` повторно проверен тем же открытым ключом; SHA-256 первого пакета — `54ee1d1ee8eb9989b84e8fe55482bf12c4c5e253a440e493b9d21c389cac8242`.
- Инструкция сборки, подписи, установки и выпуска следующей версии — [examples/echo-plugin/README.md](../../../../../examples/echo-plugin/README.md).

Для Windows остаётся ручная проверка сценария 11 на ревизии `5a4e9c2`: собрать её командой из README, добавить ключ `com.example`, установить `0.1.0`, назначить `hello` и `clock` разные сочетания, обновить на `0.2.0` и убедиться, что оба действия вызываются, а привязки сохранились.
