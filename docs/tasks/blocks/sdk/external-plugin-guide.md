# Передать пример подключения стороннего плагина с двумя действиями

**Статус** — 📥 К выполнению

[Этап 4 плана развития](../../../roadmap.md#4-принять-первую-поставку-windows) · [ТЗ блока](../../../blocks/sdk/README.md)

Подготовить переносимый пример с новым ID и двумя различимыми действиями. Описать сборку, подпись, доверие издателю, установку и выпуск следующей версии. Оставить прототип `control/ping` рабочим.

**Зависимости для старта** — [Экспортировать подписанный пакет .umpkg](../packages/export-package.md), [Описать пользовательские настройки и команды формы в манифесте](module-settings.md).

**Для сквозной проверки** — [Подключить редактор и глобальные клавиши к общему реестру](../desktop/live-shortcuts.md), [Управлять локальными пакетами из настроек](../desktop/package-management.md), [Атомарно переключать версию пакета и откатывать настройки](../packages/update-rollback.md).

## Критерии приёмки

- [ ] Следуя инструкции с чистого checkout, разработчик получает подписанный пакет нового ID. Оба действия вызываются через действующий SDK.
- [ ] На том же хосте пользователь добавляет открытый ключ, устанавливает пакет, назначает разные сочетания и обновляет пакет. Сохранившийся ID действия сохраняет привязку.

## Проверка

На Linux выполнить описанные шаги до проверки архива и IPC обоих действий. Для Windows передать пример, команду локальной сборки и шаги сценария 11.
