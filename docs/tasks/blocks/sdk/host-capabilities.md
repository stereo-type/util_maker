# Дать модулю доступ к возможностям хоста во время invoke

**Статус** — 📥 К выполнению

[Этап 3 плана развития](../../../roadmap.md#3-довести-оба-действия-до-результата-в-windows) · [ТЗ блока](../../../blocks/sdk/README.md)

Расширить JSON-RPC и цикл `run_stdio` для обращений модуля к хосту в пределах активного вызова. Зафиксировать контракты операций над кадром, выделением, буфером, настройками и секретами профиля.

**Зависимости для старта** — можно начинать на текущей ревизии.

## Критерии приёмки

- [ ] Запрос к хосту и его ответ сопоставляются с живым вызовом и объявленной возможностью. В контракте различимы отказ, потеря контекста и отмена. Дескрипторы Win32 остаются внутри адаптера.
- [ ] Кадр передаётся по ограниченной временем жизни ссылке, с форматом, размерами, шагом строки и координатами. Полноразмерное изображение не помещается в JSON-сообщение.
- [ ] `cancel` и `shutdown` принимаются, пока handler ждёт операцию. Существующий `ping` продолжает работать с прежним манифестом и протоколом v1.

## Проверка

На Linux через `make test` провести обмен с подменным хостом, отменить ожидающий вызов, проверить идентификаторы, лимит сообщения и совместимость `control`.
