# Дать дочернему процессу доступ к пикселям захваченного кадра

**Статус** — ✅ Выполнена

[Контракт доступа к кадру](../../../blocks/sdk/README.md#доступ-плагина-к-пикселям-кадра) · [Этап «После первой поставки»](../../../roadmap.md#после-первой-поставки)

Сегодня `frame.capture` возвращает `FrameRef`, а метод `ScreenService::frame_bytes` читает данные внутри хоста. Реализовать один путь передачи пикселей вне JSON для всех экранных плагинов. SDK задаёт контракт для дочернего процесса, адаптер и диспетчер хоста обеспечивают чтение в пределах вызова. Описать способ передачи, время жизни и минимальную совместимую версию API.

**Зависимости для старта** — можно брать сразу. [Захват кадра](../platform/windows/capture-frame.md), [вызовы возможностей](host-capabilities.md) и [диспетчеризация в ядре](../core/capability-dispatch.md) уже доступны. На Linux использовать тестовый источник и реальный дочерний процесс.

**Для сквозной проверки** — полученный кадр используют [выбор области OCR](../plugins/screen-ocr/select-region.md), [чтение QR](../plugins/qr-code/read-region.md) и [пипетка](../plugins/color-picker/pick-and-copy.md). Сам контракт можно принять на тестовом дочернем процессе.

## Критерии приёмки

- [x] Дочерний процесс с `screen.capture` получает байты своего снимка размером больше 1 МиБ. `FrameRef` сохраняет формат BGRA8, геометрию мониторов, `origin`, размеры и `stride`. Полноразмерные пиксели не попадают в JSON, журнал или оставшийся после выхода временный файл.
- [x] Хост сверяет возможность, владельца (модуль и активный `callId`), срок действия и границы буфера. Чужой модуль, другой вызов того же модуля, просроченная или освобождённая ссылка не дают доступа к данным.
- [x] Пока ссылка действительна, процесс получает локальный снимок в памяти и вызывает `frame.release`. После истечения `expiresInMs` он может продолжить выбор по своей копии. Завершение вызова, отмена или падение процесса освобождают оставшиеся у хоста ресурсы.
- [x] Существующие клиенты `frame.capture` и `frame.release` сохраняют совместимость. Если контракт расширен, указано, какой нижний предел `hostApi` должны объявить три новых пакета.

## Проверка

В Linux-контейнере прогнать через реальный IPC эталонный кадр с отрицательным `origin.x` и отступом в конце строки. Сверить байты по известным координатам, смоделировать истечение ссылки до и после чтения, чужой вызов и аварийный выход процесса. Для платформенного транспорта передать пользователю ревизию, команду локальной сборки и шаги проверки реального захвата на Windows 11 x64.

## Что сделано

- `FrameRef.pixelPath` — путь к BGRA8-файлу; пиксели не идут в JSON.
- `FrameRef::read_pixels()` читает локальную копию в память.
- `ScreenService` создаёт файл с правами `0600` на Unix и удаляет его при `release`, истечении TTL, завершении вызова и `Drop`.
- Тест: кадр 1024×1024 (>1 МиБ) читается и файл исчезает после release.
