## Критерии приёмки

- [ ] Процесс получает файл больше 1 МиБ с исходной длиной и хешем. Для файла 64 МиБ передача работает, превышение возвращает ошибку до сетевого запроса. Лимит JSON-RPC 1 МиБ сохраняется.
- [ ] Ссылка закреплена за маршрутом операции, доступна на чтение только в его контексте. Чужая, просроченная или освобождённая ссылка и путь, подставленный из запроса, отклоняются.
- [ ] После успеха, ошибки, отмены, выхода и падения процесса освобождаются временные ресурсы. Содержимое файла отсутствует в диагностике.

## Проверка

Linux, тест с двумя дочерними процессами, сравнением байтов и проверкой очистки. Передать пользователю проверку транспорта с большим PNG на Windows.
