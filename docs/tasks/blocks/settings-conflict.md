# Показать конфликт в редакторе шорткея

**Статус** — На ревью

**Основание** — [ТЗ блока «Настройки»](../../blocks/settings.md).

Сделать редактор с тестовым источником решений ядра. Для подключения реального переноса использовать [задачу реестра](hotkeys-переназначение.md).

## Критерии приёмки

- [ ] При внутреннем конфликте видны модуль и действие обеих сторон, доступны «Отмена» и «Переназначить».
- [ ] При системном конфликте видна функция ОС. Сохранение недоступно также с клавиатуры.
- [ ] Пользователь может указать клавиши по отдельности. При отказе в момент сохранения остаётся прежнее назначение.

## Что сделано

- В настройках появился блок «Шорткеи» с демонстрационным реестром двух действий: «Скриншоты — Снять область» и «Переводчик — Перевести текст».
- Редактор принимает клавиши по одной, показывает владельцев конфликта, системную функцию Windows и отказ регистрации; сохранение блокируется, пока конфликт не разрешён.
- «Переназначить» передаёт подтверждение с прежним владельцем; «Отмена» оставляет обе привязки. Переключатель «Имитировать отказ записи» проверяет откат при ошибке хранилища.
- «Изменить» заменяет конкретную привязку: после успешного сохранения прежняя комбинация снимается с действия, а не остаётся второй записью. При отказе записи старая привязка сохраняется.
- Поле ввода сочетания показывает полную ширину и placeholder; прежняя невидимость была из-за CSS-селектора размера чекбокса, применявшегося ко всем `input`.
- Используется переносимый `HotkeyRegistry` из задачи реестра; команды хоста — `hotkey_state_command`, `check_hotkey`, `assign_hotkey`, `set_hotkey_save_failure`.

## Проверка

Linux, контейнер `util-maker-dev:local`:

- `make test` — 63 теста; реестр конфликтов покрыт 10 тестами задачи переназначения.
- `make lint` — Clippy без предупреждений, `make fmt` — без изменений.
- `make build-windows` — установщик собран, статический интерфейс встроен в хост.

Windows (ожидает проверки пользователем):

1. Открыть настройки → «Шорткеи», выбрать «Перевести текст», ввести `Ctrl+Shift+1` — видны «Скриншоты — Снять область» и «Переводчик — Перевести текст», кнопки «Отмена» / «Переназначить».
2. «Отмена» оставляет прежние привязки; «Переназначить» передаёт сочетание переводчику, вторая привязка скриншота остаётся.
3. Ввести `Win+L` или `Alt+Tab` — видна функция Windows, «Сохранить» недоступно; с клавиатуры сохранить тоже нельзя.
4. Включить «Имитировать отказ записи» и сохранить свободное сочетание — ошибка, прежнее назначение остаётся; выключить и повторить.
5. Ввести клавиши по одной: `Ctrl`, `Shift`, `3` — поле собирает `Ctrl+Shift+3`.
