# Показать конфликт в редакторе шорткея

**Статус** — К выполнению

**Основание** — [ТЗ блока «Настройки»](../../blocks/settings.md).

Сделать редактор с тестовым источником решений ядра. Для подключения реального переноса использовать [задачу реестра](hotkeys-переназначение.md).

## Критерии приёмки

- [ ] При внутреннем конфликте видны модуль и действие обеих сторон, доступны «Отмена» и «Переназначить».
- [ ] При системном конфликте видна функция ОС. Сохранение недоступно также с клавиатуры.
- [ ] Пользователь может указать клавиши по отдельности. При отказе в момент сохранения остаётся прежнее назначение.
