# Подключить HTTP-адаптеры Яндекса и Google

**Статус** — К выполнению

**Основание** — [ТЗ блока «Провайдеры»](../../blocks/translation-providers.md).

Реализовать перевод и проверку подключения через единый интерфейс провайдера. Для проверок использовать тестовый HTTP-транспорт и отдельные профили.

## Критерии приёмки

- [ ] Для обоих API проверены endpoint, авторизация, языковые параметры, формат plain text и чтение результата.
- [ ] При переключении профиля следующий запрос уходит выбранному сервису с его ключом. Проверка подключения отправляет фиксированную фразу.
- [ ] Ошибки авторизации, HTTP 429, таймаут и отмена дают ожидаемый исход без пересылки текста второму сервису.
