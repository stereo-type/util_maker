# Обработать выделение до и после вызова переводчика

**Статус** — К выполнению

**Основание** — [ТЗ блока «Переводчик»](../../blocks/translator.md).

Реализовать состояния выбора текста на тестовых адаптерах источника и перевода. Контекст исходного окна живёт в пределах одного вызова.

## Критерии приёмки

- [ ] При готовом выделении запрос содержит ровно выбранный текст. При пустом диапазоне запрос отправляется один раз после завершения жеста.
- [ ] Esc, смена приложения в режиме ожидания и известное парольное поле дают ноль запросов.
- [ ] При неподдерживаемом источнике ручной ввод отправляется только по команде «Перевести».
