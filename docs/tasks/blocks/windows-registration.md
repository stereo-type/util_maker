# Зарегистрировать глобальное сочетание в Windows

**Статус** — ✅ Выполнена

**Основание** — [ТЗ блока «Windows»](../../blocks/windows.md).

Реализовать регистрацию и освобождение через Win32 и доставку события в ядро. Сохранить различие между системным резервом, известной занятостью и прочими отказами.

## Критерии приёмки

- [x] Win+L и Alt+Tab возвращают названия системных функций до попытки регистрации.
- [ ] При внешней занятости адаптер сообщает отказ. После освобождения сочетание регистрируется.
- [ ] На Windows пользователь проверяет единичное событие при удержании и освобождение регистрации. Для проверки использовать [первый прототип](../первый-прототип.md).

## Что сделано

- `crates/platform` — `HotkeyService` с Win32 `RegisterHotKey`/`UnregisterHotKey` на отдельном потоке message-only окна; `WM_HOTKEY` доставляется в канал, автоповтор при удержании не генерируется.
- Отказы различимы: `SystemReserved { function }` (проверка до Win32), `Occupied` (код 1409) и `Unavailable` (прочий код Win32 или платформа без поддержки).
- Хост использует собственный адаптер вместо плагина: при старте регистрирует `Ctrl+Shift+U`, меню трея получило пункты «Пауза / возобновить сочетание» и «Перерегистрировать сочетание», состояние выводится в настройках и подсказке трея.
- `scripts/hold-hotkey.ps1` занимает `Ctrl+Shift+U` из отдельного процесса для проверки внешней занятости.

## Проверка

Linux, контейнер `util-maker-dev:local`:

- `make test` — 38 тестов пройдено, в том числе 2 теста адаптера: виртуальные коды клавиш и отказ для Win+L и Alt+Tab без вызова платформы.
- `make lint` — Clippy без предупреждений, `make fmt` — без изменений.
- `make build-windows` — кросс-сборка `x86_64-pc-windows-msvc` и NSIS без предупреждений.

Windows (ожидает проверки пользователем):

1. Запустить `scripts/hold-hotkey.ps1` в отдельном PowerShell.
2. Запустить прототип: в настройках и подсказке трея — «занято другой программой», сочетание не срабатывает.
3. Нажать Enter в скрипте и выбрать в трее «Перерегистрировать сочетание» — статус «зарегистрировано», сочетание работает.
4. Пункт «Пауза / возобновить сочетание» освобождает и возвращает регистрацию.
5. Удержать `Ctrl+Shift+U` — должно появиться одно окно результата.

Пользователь подтвердил работу в Windows 11 и закрыл задачу в версии 0.4.1.
