# Проверка 0.4.5 на Windows: результаты

Дата: 2026-11-15. Машина: Windows 11 Pro 26200, два монитора
(2560×1440 слева, 3440×1440 основной). Установлено `D:\Util Maker` 0.4.5-dev.

## Прошло

- Установленная версия и журнал: `version=0.4.5 build=dev`.
- Контрольный модуль вызывается из карточки и по сочетанию.
- Добавление второго сочетания `Ctrl+Shift+9`; вызов по нему работает.
- Форма настроек переводчика строится: сервис, языки, два секретных поля, команда проверки.
- Секрет записывается в DPAPI, в `plugin-settings\org.utilmaker.translator.json` его нет.
- Ручная установка `.umpkg` из интерфейса работает: пакеты «Скриншоты» и «Переводчик» появляются в списке.

## Дефекты

| Дефект | Карточка |
| --- | --- |
| Пакеты поставки не устанавливаются: `missing field public_key` | [Устанавливать пакеты поставки](blocks/packages/bundled-packages-bootstrap.md) |

## Не проверено

- реальный перевод с ключами Яндекса/Google;
- метрики 50 вызовов;
- сон/разблокировка и перезапуск Explorer;
- масштаб 150/200 % и светлая тема;
- выделение на стыке мониторов;
- удаление приложения.
