# Проверка Util Maker на Windows

Версия: **0.4.5-dev**. Установщик: `dist/UtilMaker-Setup-0.4.5-dev.exe`.
Ревизия: `f150b03`. Проверка выполняется на Windows 11 x64.

Для проверки нужны:

- два монитора, желательно с разным DPI (например, 100 % и 150 %);
- ключи Яндекса и Google, если проверяется реальный перевод;
- Блокнот, Paint и любое приложение с выделяемым текстом (Блокнот, Edge).

## 1. Установка и первый запуск

- [ ] Запустить установщик поверх работающей предыдущей версии.
- [ ] Ожидается: приложение закрывается, устанавливается новая версия, ручное удаление не требуется.
- [ ] Первый запуск открывает настройки; после закрытия приложение остаётся в трее.
- [ ] В трее один экземпляр; повторный запуск открывает существующее окно, второй хост не появляется.
- [ ] В настройках видны три микроприложения: контрольный модуль, «Скриншоты», «Переводчик».
- [ ] У всех трёх есть иконка, версия и действия.
- [ ] В журнале `<папка установки>\logs\util-maker.log` шапка содержит `version=0.4.5 build=dev`.
- [ ] В каталоге установки есть `packages\*.umpkg` и `packages\org.utilmaker-public.json`; закрытого ключа там нет.

## 2. Менеджер пакетов

- [ ] В разделе «Установка пакета» перетащить `.umpkg` в окно или указать путь.
- [ ] «Проверить» показывает имя, версию, издателя, действия, возможности, число файлов, размер и SHA-256 отпечаток ключа.
- [ ] Установка без подтверждения отпечатка не выполняется.
- [ ] Подтвердить ключ и установить пакет — пакет появляется в списке и трее без перезапуска.
- [ ] Повторная установка тех же байтов не создаёт дубль.
- [ ] Пакет другого издателя с тем же ID отклоняется.
- [ ] «Откатить версию» возвращает предыдущую версию и её настройки.
- [ ] «Удалить пакет» убирает действие, сочетание и секреты; повторное удаление безопасно.
- [ ] При ошибке проверки/установки текущий рабочий пакет остаётся на месте, причина видна.

## 3. Шорткеи

- [ ] «Изменить» меняет сочетание; новое сразу отображается и работает.
- [ ] «+» добавляет второе сочетание тому же действию.
- [ ] «×» удаляет одно сочетание, второе продолжает работать.
- [ ] «Сбросить» возвращает рекомендованное сочетание.
- [ ] Поиск по действию/сочетанию фильтрует список.
- [ ] Ввести `Win+L` или `Alt+Tab`: видна функция Windows, сохранение запрещено.
- [ ] Занять сочетание другой программой: сохранение запрещено, показана причина.
- [ ] Назначить сочетание, занятое другим действием: предложен перенос; отмена оставляет прежнее, перенос забирает сочетание у старого действия.
- [ ] Перезапустить приложение: все назначенные сочетания восстановлены.
- [ ] «Пауза» снимает все сочетания; возобновление возвращает их.
- [ ] Отключение микроприложения освобождает его сочетания; включение возвращает.
- [ ] Удержание сочетания даёт один вызов без автоповтора.

## 4. Трей и карточка микроприложения

- [ ] В меню трея у каждого действия есть иконка из манифеста.
- [ ] Служебные пункты «Настройки», «Пауза», «Перерегистрировать», «Выход» имеют иконки.
- [ ] Вызов из трея и из карточки даёт результат.
- [ ] При отключении модуля пункт исчезает из трея без перезапуска.
- [ ] После включения пункт возвращается.
- [ ] На странице модуля нет дублирующего блока с названием/версией.
- [ ] Закрытие настроек оставляет трей; повторный запуск открывает существующее окно.

## 5. Скриншоты

- [ ] Вызвать «Снять область» из трея, сочетания и карточки.
- [ ] Ожидается: полноэкранный overlay поверх рабочего стола, панель инструментов, снимок без самой панели.
- [ ] Выделить область мышью.
- [ ] Нарисовать стрелку и рамку; «Отменить» убирает последнюю правку.
- [ ] Нажать Enter/«Копировать», вставить в Paint.
- [ ] Ожидается: размер и пиксели совпадают с выделением; панель и маркеры отсутствуют.
- [ ] Скопировать область без аннотаций.
- [ ] Esc закрывает редактор, прежний буфер не меняется.
- [ ] Занять буфер обмена, скопировать, освободить и повторить — повтор succeeds.
- [ ] Проверить выделение на левом мониторе и на стыке мониторов с разным DPI.
- [ ] Ожидается: изображение не сдвинуто и не промасштабировано.
- [ ] Повторный вызов при открытом overlay не создаёт второй редактор.
- [ ] После копирования/отмены кадр освобождён, повторный вызов работает.

## 6. Переводчик

- [ ] Открыть настройки переводчика: видны сервис, исходный/целевой язык, поля ключей Яндекса и Google.
- [ ] Ввести ключ, сохранить, перезапустить приложение — поле показывает «ключ сохранён», ключ в JSON настроек отсутствует.
- [ ] «Проверить подключение» возвращает результат или понятную ошибку.
- [ ] Выделить текст в Блокноте, нажать сочетание.
- [ ] Ожидается: окно «Перевод…» рядом с курсором, затем перевод.
- [ ] «Копировать» вставляет перевод в Блокнот с сохранением строк.
- [ ] Выделить текст в Edge и повторить.
- [ ] Выделить пустую область: появляется предложение выделить/ввести текст, HTTP-запроса нет.
- [ ] Парольное поле: запрос не отправляется.
- [ ] Удалить ключ/выбрать сервис без ключа: запрос не уходит, показано «не задан ключ».
- [ ] Ошибка провайдера (неверный ключ, 429, нет сети) видна в окне.
- [ ] Esc закрывает окно; новый вызов не показывает поздний ответ предыдущего.

## 7. Настройки по схеме манифеста

- [ ] Значения по умолчанию отображаются.
- [ ] Обязательное поле нельзя сохранить пустым.
- [ ] После закрытия и повторного открытия настройки сохранились.
- [ ] Секрет не появляется в `plugin-settings\*.json` и журнале.
- [ ] Команда формы адресуется своему модулю, показывает сообщение или ошибки полей.
- [ ] Страница нового плагина строится без специального кода в desktop.

## 8. Сбой плагина

- [ ] Запустить `scripts\kill-plugin.ps1` в отдельном PowerShell.
- [ ] Вызвать действие контрольного модуля.
- [ ] Ожидается: ошибка с модулем, действием и причиной; трей и настройки живы.
- [ ] В сообщении нет stderr, ключей и выделенного текста.
- [ ] Второй плагин продолжает отвечать.
- [ ] Нажать «Отключить плагин»: отключается именно упавший модуль.
- [ ] Закрыть сообщение без отключения: плагин остаётся включённым, вызов можно повторить.
- [ ] После перезапуска отключённый плагин остаётся отключённым.

## 9. Метрики

- [ ] `.\scripts\measure-windows.ps1 -InvokeBenchmark -InvokeCount 50`.
- [ ] Ожидается: 50 холодных вызовов выполняются автоматически.
- [ ] Вывод содержит p95 отдельно по `moduleId + actionId` и `cold=true/false`.
- [ ] Виден размер каждой выборки; неполная выборка отмечена.
- [ ] В `util-maker.jsonl` нет текста перевода, снимков, ключей и URL с секретами.
- [ ] Память и CPU считаются по хосту и дочерним процессам.

## 10. Сон, разблокировка, Explorer

- [ ] Перевести ПК в сон и разбудить.
- [ ] Ожидается: трей виден, сочетания работают.
- [ ] Заблокировать и разблокировать сессию — сочетания работают.
- [ ] Перезапустить Explorer — трей появляется, сочетания работают.
- [ ] Включить паузу, заблокировать/разблокировать — пауза сохраняется.
- [ ] Завершить работу через «Выход» — все сочетания сняты, процессы модулей завершены.
- [ ] Запустить снова — действия и сочетания доступны.

## 11. Клавиатура, темы, масштаб

- [ ] Пройти Tab/Enter/Esc: фокус виден, все команды доступны.
- [ ] Диалог сочетания удерживает Tab внутри, Esc возвращает фокус на кнопку.
- [ ] Проверить масштаб 100 %, 150 %, 200 %.
- [ ] Проверить светлую и тёмную тему.
- [ ] У иконок есть доступные имена и подсказки; ошибки выражены текстом.

## 12. Обновление и повторный запуск

- [ ] Установить следующую версию одного пакета.
- [ ] Ожидается: версия хоста и второй пакет не затронуты.
- [ ] Настройки и привязки обновлённого пакета сохранились.
- [ ] Повторный запуск приложения не создаёт второй хост и не переустанавливает пакеты.
- [ ] Удалить приложение; пользовательские настройки и журнал остаются до ручного удаления.

## 13. Что считать успехом

Проверка считается пройденной, если:

- все пункты отмечены;
- нет падений хоста, зависших процессов модулей и второго экземпляра;
- ошибки показываются пользователю и не раскрывают секреты;
- после перезапуска состояние, настройки и привязки сохраняются.

При провале пункта записать: номер раздела, действие, ожидаемый и фактический результат, версию `0.4.5`, ревизию `f150b03`, путь к журналу.
