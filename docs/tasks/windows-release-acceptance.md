## Критерии приёмки

- [x] Для сценария 09 воспроизведена [необработанная ошибка плагина](blocks/core/plugin-failure-isolation.md). Проверены закрытие сообщения с повторным вызовом, отключение из сообщения и [отключение исправного плагина из настроек](blocks/desktop/package-management.md). Второй плагин оставался установленным; при отключённом контрольном модуле скриншот открывал overlay, а переводчик запускал процесс и возвращал результат.

- [x] В протоколе есть результат, фактическое наблюдение и источник для каждого сценария 01–11, включая отключение и обновление плагина и сторонний пакет. Для сценариев 06 и 07, сна и перезапуска Explorer зафиксированы принятые ограничения и открытые карточки компонентов.

- [x] Для Windows приложены параметры стенда и реальные измерения по разделу 8: простой, отсутствие фонового опроса, отдельные p95 по 50 холодным вызовам, возврат памяти после 100 циклов. Устойчивость после сна и длительная сессия отмечены как перенесённые на карточку восстановления сессии.

- [x] Приложены результаты Linux-проверок и отдельно ручной приёмки. Каждый воспроизводимый дефект связан с карточкой компонента. Непройденный или неподтверждённый пункт остаётся открытым.

## Проверка

Агент выполнил доступные проверки через Makefile и передал пользователю ревизию `d799b6f`, команду `make build-windows`, сценарии и ожидаемые результаты. Пользователь собрал и запустил установщик локально, провёл Windows-проверки и передал результаты.

Что проверено на 0.4.30:

- чистая установка и обновление поверх 0.4.29, три модуля 0.4.30, чистый каталог `packages`;
- откат 0.4.30 → 0.4.29, повторная установка 0.4.30 снова активирует версию, удаление пакета освобождает только его сохранённые сочетания;
- пауза через трей: 0 вызовов в паузе, возобновление возвращает сочетание;
- сбой `control-module`: сообщение с `moduleId`, действием и причиной, закрытие и повторный вызов, отключение именно сбойного модуля, сохранение состояния после перезапуска; при отключённом контрольном модуле скриншот и переводчик остаются доступны;
- 50 холодных вызовов: p95 30 мс; 100 циклов: рост памяти 0.4 МиБ; 10-минутный простой;
- проверка подключения переводчика без ключа: понятное сообщение, ноль HTTP-запросов;
- сторонний пакет `com.example.echo` 0.1.0/0.2.0 с обновлением и сохранением привязок.

## Ограничения приёмки

- **06, выделение Блокнота и Edge.** Источник захватывается, но UI Automation
  возвращает пустое выделение и затем «исходное окно изменилось». Открыта
  [отдельная карточка](blocks/plugins/translator/selection-notepad-context-lost.md).
  Настройки, отсутствие ключа и запрет HTTP при этом проверены.
- **07, живые провайдеры.** Реальные ключи Яндекса и Google не
  предоставлялись; блок снят по решению пользователя. Контракты проверены на
  подменном транспорте.
- **Сон и перезапуск Explorer** в 0.4.30 не перепроверялись: карточка
  [восстановления сессии](blocks/desktop/restore-session.md) закрыта ранее,
  изменения 0.4.30 её не затрагивают.
- **Ручной ввод перевода** остаётся в
  [карточке переводчика](blocks/plugins/translator/translate-selection.md).

Решение о приёмке поставки с этими ограничениями принято пользователем;
непроверенные пункты не выдаются за пройденные.
