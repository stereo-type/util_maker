## Критерии приёмки

- [ ] Для сценария 09 воспроизведена [необработанная ошибка плагина](blocks/core/plugin-failure-isolation.md). Проверены закрытие сообщения с повторным вызовом, отключение из сообщения и [отключение исправного плагина из настроек](blocks/desktop/package-management.md). Второй плагин доступен во всех трёх случаях.

- [ ] В протоколе есть результат, фактическое наблюдение и источник проверки для каждого сценария 01–11, включая реальный перевод через оба профиля, отключение и обновление плагина и сторонний пакет.
- [ ] Для Windows приложены параметры стенда и реальные измерения по разделу 8: простой, отсутствие фонового опроса, отдельные p95 по 50 холодным вызовам, возврат памяти после 100 циклов. Проверены устойчивость после сна и длительная сессия.
- [ ] Приложены результаты Linux-проверок и отдельно ручной приёмки. Каждый воспроизводимый дефект связан с карточкой компонента. Непройденный или неподтверждённый пункт остаётся открытым.

## Проверка

Агент выполняет доступные проверки через Makefile и передаёт пользователю ревизию, команду `make build-windows`, сценарии и ожидаемые результаты. Пользователь собирает и запускает установщик локально, проводит Windows-проверки и передаёт результаты.
