## Прогон 0.4.23

- Установка поверх 0.4.22: версия 0.4.23, три микроприложения 0.4.23, настройки открылись.
- Скриншот: выделение 300×300, редактор, «Копировать» — в буфере изображение 300×300; «Сохранить» создал PNG; Esc закрыл редактор.
- Метрики: 50 холодных вызовов с `-Hotkey Ctrl+Shift+9`, p95 по control; скрипт выводит размер выборки.
- Сбой: `kill-plugin.ps1` + вызов control дал `module_crashed` в журнале и сообщение в интерфейсе.
- Чистая установка проверена: `shortcuts.json` пуст, пакеты поставки восстановлены.
- Не проверено: откат/удаление пакета, трей и пауза, реальный перевод с ключами, сон/блокировка, Explorer, конфликт сочетаний.
