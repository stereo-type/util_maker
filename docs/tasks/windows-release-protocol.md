## Принятые ограничения

- **06, выделение Блокнота и Edge.** Источник теперь захватывается до открытия
  окон (в журнале виден PID и окно), но UI Automation возвращает пустое
  выделение и затем «исходное окно изменилось». Открыта карточка
  [Читать выделение Блокнота через UI Automation](blocks/plugins/translator/selection-notepad-context-lost.md).
  Проверка настроек, отсутствия ключа и запрета HTTP при этом пройдена.
- **07, живые провайдеры.** Реальные ключи Яндекса и Google не
  предоставлялись. По решению пользователя блок по ключам снят; контракты
  проверены на подменном транспорте, реальный сетевой перевод не выполнялся.
- **Сон и перезапуск Explorer** в 0.4.30 не перепроверялись; карточка
  [Восстанавливать трей и регистрации](blocks/desktop/restore-session.md)
  закрыта ранее, изменения 0.4.30 её не затрагивают.
- **Ручной ввод перевода** остаётся в карточке
  [Связать выделение и окно результата](blocks/plugins/translator/translate-selection.md).

## Итог

Установщик 0.4.30 принят с ограничениями выше. Общая карточка закрыта по
решению пользователя: непройденные пункты не выдаются за проверенные и
остаются отдельными задачами компонентов.
