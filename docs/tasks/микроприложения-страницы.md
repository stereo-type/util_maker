# Показать установленные микроприложения и их настройки

**Статус** — К выполнению

**Основание** — замечание пользователя к демонстрационному экрану «Шорткеи»: общие настройки должны показывать установленные плагины, их действия и собственные параметры, а сочетание должно принадлежать действию внутри микроприложения, а не ядру.

Сейчас модель данных уже использует пару `moduleId + actionId`, но интерфейс показывает только демонстрационный список действий. Нужен настоящий экран микроприложений поверх реестра пакетов.

## Критерии приёмки

- [ ] Основной экран показывает установленные пакеты: иконку, имя, версию, состояние и переключатель.
- [ ] У каждого микроприложения есть страница со списком действий, их сочетаниями и собственными настройками из манифеста.
- [ ] Сочетание назначается действию `moduleId + actionId`; страница модуля не требует правки ядра.
- [ ] Демонстрационные записи «Скриншоты» и «Переводчик» заменены реальными пакетами или явно помечены как отсутствующие.
- [ ] Переход между списком и страницей модуля работает с клавиатуры, настройки сохраняются.
