# Подготовить первый прототип для локальной проверки на Windows

**Статус** — К выполнению

Основание — разделы 2, 9 и 10 [общего ТЗ](../ТЗ.md). Начать с `make dev-setup`. Реализовать минимальную цепочку от события в трее или глобального шорткея до вызова контрольного модуля в отдельном процессе. Добавить локальную Docker-сборку под `x86_64-pc-windows-msvc` с cargo-xwin, LLVM/LLD и NSIS.

## Критерии приёмки

- [ ] На Ubuntu тест переносимого ядра вызывает контрольный handler через IPC без рабочего стола.
- [ ] Пользователь после получения ревизии запускает `make build-windows` локально. Цель выводит путь к полученному установщику в `dist/`.
- [ ] Пользователь устанавливает прототип на Windows 11, открывает и закрывает настройки, вызывает контрольный модуль шорткеем и видит результат. В задаче записаны ревизия, результат ручной проверки и первые замеры по разделу 8 ТЗ.
