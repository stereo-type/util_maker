Util Maker — прототип 0.4.22
==========================

Что это
-------
Прототип резидентного хоста: трей, одно глобальное сочетание Ctrl+Shift+U,
запуск контрольного модуля отдельным процессом по JSON-RPC и показ результата.

Как проверить
-------------
1. Запустите ярлык «Util Maker» на рабочем столе или в меню «Пуск».
   При первом запуске откроется окно настроек.
2. Закройте настройки крестиком — приложение останется в трее.
3. Нажмите Ctrl+Shift+U в любой программе: появится окно с сообщением
   контрольного модуля. Esc закрывает окно.
4. Клик по иконке в трее открывает настройки. Меню трея: «Настройки»,
   «Проверить связь», «Выход».
5. Повторный запуск ярлыка показывает настройки уже работающего экземпляра.
6. В настройках можно включить автозапуск при входе в Windows.

Где лежат данные
----------------
Журнал:  <папка установки>\logs\util-maker.log
         (путь виден в настройках; при недоступности каталога установки —
          %LOCALAPPDATA%\Util Maker\logs\util-maker.log)
Состояние: %LOCALAPPDATA%\org.utilmaker.prototype\prototype-state.json

Удаление
--------
Параметры Windows → Приложения → Util Maker (прототип) → Удалить.
Настройки и журнал удаляются вручную, если они больше не нужны.

Это прототип для проверки цепочки «трей → сочетание → отдельный процесс →
результат». Полные настройки, менеджер пакетов и штатные модули появятся
в следующих задачах.
