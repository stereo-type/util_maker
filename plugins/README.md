# Плагины Util Maker

Каждый плагин — отдельный каталог и отдельный пакет. Хост не импортирует
внутренние модули плагина: он читает манифест и общается по JSON-RPC 2.0 через
stdin/stdout дочернего процесса.

## Состав каталога

```text
plugins/<id>/
  Cargo.toml
  manifest.json
  src/
  assets/
  README.md
```

- `manifest.json` — стабильный ID, издатель, версия, диапазон `hostApi`,
  платформа, действия и запрошенные возможности.
- `src/` — процесс плагина и/или переносимая логика.
- `assets/` — иконка и ресурсы, попадающие в пакет.
- `README.md` — действия, сборка и проверка.

## Жизненный цикл

1. Хост читает манифест, не запуская процесс.
2. По действию запускает исполняемый файл плагина.
3. Передаёт `initialize`, проверяет API и возможности.
4. Передаёт `invoke` с `callId` и `actionId`.
5. Завершает процесс после действия; отмена и зависание обрабатываются ядром.

## Пакет

Каталог плагина упаковывается в `.umpkg`: манифест, подпись Ed25519 и файлы с
SHA-256. Проверка описана в [формате пакета](../docs/blocks/packages/package-format.md).
Экспорт из интерфейса и установка архива пока не реализованы.

## Текущие плагины

| Плагин | Состояние |
| --- | --- |
| `control` | Рабочий контрольный процесс с действием `ping`. |
| `screenshot` | Переносимое сведение кадра и аннотаций; процесс и overlay ещё не упакованы. |
| `translator` | Процесс с действием `translate`, состояния выбора и HTTP-провайдеры; UI Automation и окно результата ещё не упакованы. |
| `color-picker` | Процесс `pick-color`, выбор пикселя лупой и копирование HEX/RGB; overlay ещё не упакован. |
| `screen-ocr` | Процесс `recognize-region`, языки, выбор области и локальный Tesseract; overlay и окно результата ещё не упакованы. |
