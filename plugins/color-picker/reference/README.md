# Эталон пипетки цвета

[ТЗ плагина](../../../docs/blocks/plugins/color-picker/README.md) · [Задача](../../../docs/tasks/blocks/plugins/color-picker/sample-pixel.md)

Файлы созданы командой `make color-picker-reference`:

- [`sample.png`](sample.png) — видимые пиксели эталонного кадра;
- [`sample.json`](sample.json) — геометрия, BGRA-байты и ожидаемые строки для автоматической проверки.

## Геометрия

| Параметр | Значение |
| --- | --- |
| Формат | BGRA8, верхняя строка первая |
| Начало кадра | `(-40, -20)` |
| Размер | `240 × 160` |
| `stride` тестового буфера | `976` байт (`240 × 4 + 16`) |
| Монитор | тот же прямоугольник, что и кадр |

PNG хранит только видимые RGB-пиксели. В тестовом BGRA-буфере каждая строка
дополнена 16 байтами; эти байты не должны попадать в выборку. Координата
пикселя PNG равна `физическая координата − начало кадра`.

## Контрольные точки

| Точка | Физические координаты | Пиксель PNG | BGRA | HEX | CSS RGB |
| --- | --- | --- | --- | --- | --- |
| Целевой цвет | `(0, 0)` | `(40, 20)` | `ED 80 2F FF` | `#2F80ED` | `rgb(47, 128, 237)` |
| Сосед справа | `(1, 0)` | `(41, 20)` | `11 22 33 FF` | `#332211` | `rgb(51, 34, 17)` |
| Сосед снизу | `(0, 1)` | `(40, 21)` | `44 55 66 FF` | `#665544` | `rgb(102, 85, 68)` |
| Чёрный | `(-40, -20)` | `(0, 0)` | `00 00 00 FF` | `#000000` | `rgb(0, 0, 0)` |
| Белый | `(-39, -20)` | `(1, 0)` | `FF FF FF FF` | `#FFFFFF` | `rgb(255, 255, 255)` |
| Альфа не влияет | `(-38, -20)` | `(2, 0)` | `10 20 30 00` | `#302010` | `rgb(48, 32, 16)` |

## Проверка

```sh
make color-picker-check
```

Тест читает `sample.json`, собирает BGRA-буфер с отступом в конце строки и
сверяет оба формата для каждой точки. Для ручной проверки на Windows откройте
`sample.png` в масштабе 1:1 и выберите точку `(40, 20)` в координатах
изображения — плагин должен показать значение из строки «Целевой цвет».
