# Плагин «QR-коды»

Переносимая часть микроприложения `org.utilmaker.qr-code`: кодирование текста
в QR Code Model 2 и отрисовка матрицы в физических пикселях.

- Крейт — `util-maker-qr-code`;
- коррекция ошибок — M;
- Unicode кодируется в UTF-8 с ECI 26;
- белое поле — не меньше четырёх модулей;
- масштаб модулей — целое число пикселей.

## Кодирование

`QrMatrix::encode(text)` возвращает матрицу без белого поля. Пустая строка
даёт `EncodeError::EmptyInput`, слишком длинный текст — `EncodeError::TooLong`
без усечения. Версия QR выбирается автоматически от 1 до 40.

`QrMatrix::render(width, height)` вписывает код в окно. Если даже один пиксель
на модуль не помещается, возвращается `RenderError::TooSmall`; нулевое окно —
`RenderError::EmptyWindow`. Код центрируется, свободное место остаётся белым.

## Контрольные строки

| Назначение | Строка | Ожидание |
| --- | --- | --- |
| URL с параметрами | `https://example.com/search?q=%D0%BF%D1%80%D0%B8%D0%B2%D0%B5%D1%82&lang=ru#top` | Совпадает побайтно |
| Unicode и пробелы | `  Привет, мир! 👋\nСтрока 2\t— конец  ` | Совпадает побайтно, включая крайние пробелы и переводы строк |
| Пустой ввод | `""` | `EmptyInput` |
| Переполнение | 5000 символов `a` | `TooLong`, без усечения |

## Декодирование

`QrFrame` принимает кадр BGRA8 и физические координаты, `decode_qr`
вырезает область и ищет QR локально через `rqrr`. Размеры, `stride` и
границы выделения проверяются до чтения пикселей.

`GrayImage::decode` возвращает `DecodeOutcome`:

| Исход | Что показывает окно |
| --- | --- |
| `Text(QrText)` | Точный текст без открытия ссылок и исполнения команд |
| `NoCode` | QR не найден, предложить новый выбор |
| `Damaged` | QR повреждён, предложить новый выбор |
| `Multiple { count }` | Найдено несколько кодов, попросить выделить один |
| `UnsupportedEncoding` | Кодировка не поддерживается |
| `BinaryPayload` | Двоичные данные нельзя показать текстом |
| `Empty` | Пустая строка, копировать нечего |

Модуль не пишет в буфер обмена и не запускает внешние приложения: это
делает только команда «Копировать» в окне предпросмотра.

## Эталоны декодирования

`reference/sample.json` хранит растр, выделение и ожидаемый исход для
каждого случая. Изображения созданы сторонним генератором `segno`:
прямой и повёрнутый QR, UTF-8 с ECI, ASCII без ECI, Wi-Fi и командная
строка, два кода в области, пустая область, повреждённый код,
неподдерживаемая кодировка и двоичная нагрузка.

```sh
make qr-code-reference  # пересоздать эталоны (python3-segno, Pillow)
make qr-code-check      # проверить кодирование, отрисовку и декодирование
```

## Проверка

```sh
make qr-code-check
```

Тест кодирования рисует QR в растр и декодирует его независимой библиотекой
`rqrr`; дополнительно проверяются пустой ввод, переполнение, слишком
маленькое окно, целый масштаб и поле не меньше четырёх модулей.
Тест декодирования проходит по фиксированным эталонам из `reference/`:
прямой и повёрнутый QR, UTF-8 с ECI, ASCII без ECI, Wi-Fi и командная
строка, два кода в области, пустая область, повреждённый код,
неподдерживаемая кодировка и двоичная нагрузка.
