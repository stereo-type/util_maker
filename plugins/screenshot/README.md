# Плагин «Скриншоты»

Микроприложение снимает область экрана, позволяет добавить стрелку или рамку и
копирует результат. Плагин поставляется отдельным пакетом и работает офлайн;
захват рабочего стола и буфер обмена подключаются через возможности хоста.

## Состав

```text
manifest.json       манифест org.utilmaker.screenshot, действие capture-region
src/main.rs         процесс плагина: initialize/invoke/shutdown через stdio
src/lib.rs          Frame, Selection, Annotation и сведение результата
src/editor.rs       состояние выбора, аннотаций и копирования
assets/icon.png     иконка пакета
```

Точка входа — `screenshot-plugin` (`screenshot-plugin.exe` на Windows). Сейчас
действие `capture-region` возвращает машинную ошибку `2001`
`capture_unavailable`, пока Windows-адаптер не передал кадр. Неизвестное действие
возвращает `ACTION_NOT_FOUND`.

## Редактор

`EditorSession` не зависит от окна и проверяется на эталонном кадре:

- `begin` принимает кадр; повторный вызов возвращает `AlreadyActive`;
- `select`, `add_annotation`, `undo_last` меняют выбор и аннотации;
- `copy` пишет только выбранную область; при занятом буфере сохраняет кадр и
  аннотации для повтора;
- `escape` освобождает кадр, не трогая прежний буфер;
- после успешного копирования кадр и аннотации освобождаются.

Реальное overlay-окно, захват мониторов и системный буфер обмена подключаются в
задачах Windows-адаптера.

## Проверка

```sh
make screenshot-check
```

Цель собирает процессы и запускает:

- `cargo test -p util-maker-screenshots` — сведение кадра и редактор;
- `cargo test -p util-maker-core --test screenshot_module` — манифест, запуск
  отдельного процесса, ошибка без кадра и `ACTION_NOT_FOUND`.

Полная проверка проекта — `make check`.
