# Плагин «Скриншоты»

Переносимая логика будущего микроприложения: вырезание области кадра, стрелка,
рамка и отмена последней аннотации в физических пикселях виртуального рабочего
стола.

Пока это библиотека без процесса и overlay. Для полноценного плагина нужны
манифест, исполняемый файл, захват экрана и окно редактора; они появятся в
следующих задачах.

- Крейт — `util-maker-screenshots`
- Проверка — `make test`
- Логика — [`src/lib.rs`](src/lib.rs)
